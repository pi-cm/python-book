# 레퍼런스 B. 키워드와 연산자

변수 이름을 지었는데 `SyntaxError`가 난다면 키워드와 겹쳤을 가능성이 큽니다. 식이 예상과 다른 값을 낸다면 연산자 우선순위를 의심해 볼 차례고요. 이 레퍼런스는 그럴 때 펼쳐 보라고 만들었습니다. Python 3.12의 키워드 35개와 소프트 키워드 4개, 모든 연산자와 대응하는 특수 메서드, 공식 문서와 같은 순서의 우선순위 표를 담았습니다.

키워드 목록은 직접 확인할 수 있어요.

```python
import keyword
print(len(keyword.kwlist))     # 35
print(keyword.softkwlist)      # ['_', 'case', 'match', 'type']
print(keyword.iskeyword('class'), keyword.issoftkeyword('match'))   # True True
```

## 소프트 키워드 4개

**소프트 키워드**는 특정 문법 위치에서만 키워드로 동작하고, 나머지 자리에서는 평범한 이름입니다. 그래서 `match = 1`이나 `type(3)`처럼 써도 오류가 나지 않아요. 기존 코드를 깨지 않고 새 문법을 넣으려고 만든 장치입니다.

> **버전별 차이**  
> 키워드 목록(`kwlist`)은 3.10부터 3.13까지 35개로 같습니다. 소프트 키워드는 3.10에서 `_` `case` `match`가 생겼고, 3.12에서 `type`이 더해졌습니다. 같은 3.12에서 `def f[T](x: T)`처럼 함수·클래스 이름 뒤에 타입 매개변수를 적는 문법도 함께 들어왔어요.

| 소프트 키워드 | 뜻 | 짧은 예 | 장 |
|---|---|---|---|
| `match` | 패턴 매칭 문을 엽니다(3.10+). | `match command:` | 04 |
| `case` | `match` 안에서 패턴 하나를 적습니다(3.10+). | `case [x, y]:` | 04 |
| `_` | `case _:`처럼 쓰면 무엇이든 맞는 와일드카드 패턴(3.10+). | `case _:` | 04 |
| `type` | 타입 별칭 문(3.12+). 평소엔 `type()` 함수 이름 그대로입니다. | `type Point = tuple[float, float]` | — |

## 연산자 전체

연산자마다 대응하는 특수 메서드가 있어서, 클래스에 그 메서드를 정의하면 우리 객체도 그 연산자를 쓸 수 있습니다(11장). 이항 산술·비트 연산자는 왼쪽 객체의 메서드가 `NotImplemented`를 돌려주면 오른쪽 객체의 반사 메서드를 대신 부릅니다. 이름 앞에 `r`이 붙은 `__radd__`, `__rsub__`, `__rmul__` 같은 메서드예요. 예 칸에서 쉼표로 나열한 예는 결과도 같은 순서로 나열했습니다.

### 산술

| 연산자 | 뜻 | 예 → 결과 | 특수 메서드 |
|---|---|---|---|
| `+` | 덧셈, 시퀀스 이어 붙이기 | `7 + 2, [1] + [2]` → `9, [1, 2]` | `__add__` |
| `-` | 뺄셈, 집합의 차집합 | `7 - 2, {1, 2} - {2}` → `5, {1}` | `__sub__` |
| `*` | 곱셈, 시퀀스 반복 | `7 * 2, 'ab' * 2` → `14, 'abab'` | `__mul__` |
| `/` | 나눗셈. 결과는 늘 `float` | `7 / 2, 6 / 2` → `3.5, 3.0` | `__truediv__` |
| `//` | 몫(내림 나눗셈) | `7 // 2, -7 // 2` → `3, -4` | `__floordiv__` |
| `%` | 나머지. 부호는 나누는 수를 따름. 문자열 서식에도 씀 | `7 % 2, -7 % 2` → `1, 1` | `__mod__` |
| `**` | 거듭제곱 | `2 ** 10, 4 ** 0.5` → `1024, 2.0` | `__pow__` |
| `@` | 행렬 곱(3.5+). 내장 타입에는 구현이 없어 NumPy 배열 등에서 씀 | `[[1]] @ [[1]]` → `TypeError` | `__matmul__` |
| `-x` | 부호 반전(단항) | `-(-3)` → `3` | `__neg__` |
| `+x` | 부호 유지(단항) | `+True` → `1` | `__pos__` |

### 비교

| 연산자 | 뜻 | 예 → 결과 | 특수 메서드 |
|---|---|---|---|
| `==` | 값이 같은지 | `1 == 1.0` → `True` | `__eq__` |
| `!=` | 값이 다른지 | `'a' != 'A'` → `True` | `__ne__` |
| `<` | 작은지. 연쇄 비교 가능 | `1 < 2 < 3` → `True` | `__lt__` |
| `<=` | 작거나 같은지 | `[1, 2] <= [1, 3]` → `True` | `__le__` |
| `>` | 큰지 | `'b' > 'a'` → `True` | `__gt__` |
| `>=` | 크거나 같은지 | `(1, 2) >= (1, 2)` → `True` | `__ge__` |

### 논리

| 연산자 | 뜻 | 예 → 결과 | 특수 메서드 |
|---|---|---|---|
| `and` | 둘 다 참인지. 단축 평가, 피연산자 값을 돌려줌 | `3 and 5, 0 and 5` → `5, 0` | 없음(`__bool__`로 판정) |
| `or` | 하나라도 참인지. 단축 평가 | `0 or 5, 3 or 5` → `5, 3` | 없음(`__bool__`로 판정) |
| `not` | 논리 부정. 늘 `bool` | `not 0, not 'a'` → `True, False` | 없음(`__bool__`로 판정) |

### 비트

| 연산자 | 뜻 | 예 → 결과 | 특수 메서드 |
|---|---|---|---|
| `&` | 비트 AND, 집합의 교집합 | `0b1100 & 0b1010, {1, 2} & {2, 3}` → `8, {2}` | `__and__` |
| \| | 비트 OR, 집합의 합집합, 딕셔너리 병합(3.9+) | `0b1100` \| `0b1010`, `{1}` \| `{2}`, `{'a': 1}` \| `{'b': 2}` → `14, {1, 2}, {'a': 1, 'b': 2}` | `__or__` |
| `^` | 비트 XOR, 집합의 대칭 차집합 | `0b1100 ^ 0b1010` → `6` | `__xor__` |
| `~` | 비트 반전(단항). `~x == -x - 1` | `~5` → `-6` | `__invert__` |
| `<<` | 왼쪽 시프트(2의 n제곱을 곱함) | `1 << 4` → `16` | `__lshift__` |
| `>>` | 오른쪽 시프트(2의 n제곱으로 나누고 내림) | `100 >> 2, -9 >> 1` → `25, -5` | `__rshift__` |

### 멤버십·식별

| 연산자 | 뜻 | 예 → 결과 | 특수 메서드 |
|---|---|---|---|
| `in` | 포함되어 있는지 | `2 in [1, 2], 'k' in {'k': 1}` → `True, True` | `__contains__` |
| `not in` | 포함되어 있지 않은지 | `'z' not in 'abc'` → `True` | `__contains__`의 반대 |
| `is` | 같은 객체인지 | `None is None` → `True` | 없음(재정의 불가) |
| `is not` | 다른 객체인지 | `[] is not []` → `True` | 없음(재정의 불가) |

### 조건식·왈러스

| 연산자 | 뜻 | 예 → 결과 | 특수 메서드 |
|---|---|---|---|
| `a if c else b` | `c`가 참이면 `a`, 아니면 `b` | `'짝' if 4 % 2 == 0 else '홀'` → `'짝'` | 없음 |
| `:=` | 식 안에서 대입하고 그 값을 돌려줌(3.8+) | `(n := 10) * 2` → `20` | 없음 |

### 접근·호출

| 연산자 | 뜻 | 예 → 결과 | 특수 메서드 |
|---|---|---|---|
| `x[i]` | 인덱싱, 슬라이싱 | `'abc'[1], 'abc'[::-1]` → `'b', 'cba'` | `__getitem__` |
| `f(x)` | 호출 | `len('abc')` → `3` | `__call__` |
| `x.attr` | 속성 접근 | `'abc'.upper()` → `'ABC'` | `__getattribute__`, `__getattr__` |

### 할당과 복합 할당

복합 할당 `x op= y`는 먼저 `__iop__` 메서드(제자리 연산)를 찾고, 없으면 `x = x op y`로 계산합니다. 정수·문자열·튜플처럼 바꿀 수 없는 객체는 새 객체가 만들어지고, 리스트처럼 바꿀 수 있는 객체는 그 자리에서 바뀝니다. `a = b = []` 뒤에 `a += [1]`을 하면 `b`도 `[1]`이 되는 이유예요.

| 연산자 | 같은 뜻 | `x = 12`일 때 → 결과 `x` | 특수 메서드 |
|---|---|---|---|
| `=` | 이름에 값을 묶음 | `x = 12` → `12` | 없음 |
| `+=` | `x = x + 5` | `x += 5` → `17` | `__iadd__` |
| `-=` | `x = x - 5` | `x -= 5` → `7` | `__isub__` |
| `*=` | `x = x * 5` | `x *= 5` → `60` | `__imul__` |
| `/=` | `x = x / 5` | `x /= 5` → `2.4` | `__itruediv__` |
| `//=` | `x = x // 5` | `x //= 5` → `2` | `__ifloordiv__` |
| `%=` | `x = x % 5` | `x %= 5` → `2` | `__imod__` |
| `**=` | `x = x ** 2` | `x **= 2` → `144` | `__ipow__` |
| `&=` | `x = x & 10` | `x &= 10` → `8` | `__iand__` |
| \|= | `x = x` \| `10` | `x` \|= `10` → `14` | `__ior__` |
| `^=` | `x = x ^ 10` | `x ^= 10` → `6` | `__ixor__` |
| `<<=` | `x = x << 2` | `x <<= 2` → `48` | `__ilshift__` |
| `>>=` | `x = x >> 2` | `x >>= 2` → `3` | `__irshift__` |
| `@=` | `x = x @ y` | 내장 타입에는 없음 | `__imatmul__` |

## 연산자 우선순위

공식 문서 "Operator precedence" 표와 같은 순서로, **위가 먼저(높은 우선순위)** 계산됩니다. 한 칸 안의 연산자는 우선순위가 같아요. 오른쪽 열의 예는 바로 아래 순위의 연산자와 섞었을 때 이 순위가 먼저 묶인다는 것을 보여 줍니다. 3장에서 말했듯 헷갈리면 괄호를 치는 게 가장 좋습니다.

| 순위 | 연산자 | 이름 | 확인 예 → 결과 |
|---|---|---|---|
| 1 | `(...)` `[...]` `{...}` | 괄호, 리스트·딕셔너리·집합 표기 | `(2 + 3) * 4` → `20` |
| 2 | `x[i]` `x[i:j]` `f(...)` `x.attr` | 인덱싱, 슬라이싱, 호출, 속성 | `-'abc'.count('a')` → `-1` |
| 3 | `await x` | 기다리기 | — |
| 4 | `**` | 거듭제곱 | `-2 ** 2` → `-4` |
| 5 | `+x` `-x` `~x` | 단항 양수·음수·비트 반전 | `~1 * 2` → `-4` |
| 6 | `*` `@` `/` `//` `%` | 곱셈 계열 | `2 + 3 * 4` → `14` |
| 7 | `+` `-` | 덧셈, 뺄셈 | `1 + 2 << 1` → `6` |
| 8 | `<<` `>>` | 시프트 | `1 << 1 & 1` → `0` |
| 9 | `&` | 비트 AND | `6 & 3 ^ 1` → `3` |
| 10 | `^` | 비트 XOR | `3 ^ 1` \| `1` → `3` |
| 11 | \| | 비트 OR | `1` \| `2 == 3` → `True` |
| 12 | `in` `not in` `is` `is not` `<` `<=` `>` `>=` `!=` `==` | 비교, 멤버십, 식별 | `not 1 == 2` → `True` |
| 13 | `not x` | 논리 NOT | `not 0 and 0` → `0` |
| 14 | `and` | 논리 AND | `1 or 0 and 0` → `1` |
| 15 | `or` | 논리 OR | `1 if 0 or 1 else 2` → `1` |
| 16 | `if` – `else` | 조건식 | `(lambda: 1 if 0 else 2)()` → `2` |
| 17 | `lambda` | 람다식 | — |
| 18 | `:=` | 대입 표현식(왈러스) | `(y := 1 + 2)` → `3` |

### 결합 방향 메모

- **같은 순위의 이항 연산자는 왼쪽부터** 묶습니다. `10 - 5 - 2`는 `(10 - 5) - 2`라서 `3`입니다.
- **`**`만 오른쪽부터** 묶습니다. `2 ** 3 ** 2`는 `2 ** (3 ** 2)`라서 `512`예요.
- `**`는 왼쪽의 단항 연산자보다 강하지만 **오른쪽의 단항 연산자보다는 약합니다**. `-2 ** 2`는 `-(2 ** 2)`라서 `-4`이고, `2 ** -1`은 `2 ** (-1)`이라서 `0.5`입니다.
- **비교는 결합하지 않고 이어집니다.** `a < b < c`는 `(a < b) < c`가 아니라 `a < b and b < c`이고, `b`는 한 번만 계산합니다. 그래서 `1 < 3 > 2`는 `True`입니다.
- **조건식은 오른쪽부터** 묶습니다. `a if c1 else b if c2 else d`는 `a if c1 else (b if c2 else d)`입니다.
- 대입 `a = b = c = 5`는 연산자가 아니라 문장입니다. 오른쪽 값 `5`를 왼쪽의 이름들에 왼쪽부터 차례로 묶습니다.
- 비트 연산자는 비교보다 우선순위가 높습니다. C나 자바와 반대라서 `x & 1 == 0`은 `(x & 1) == 0`으로 계산돼요.

```python
print(10 - 5 - 2)          # 3
print(2 ** 3 ** 2)         # 512
print(-2 ** 2, 2 ** -1)    # -4 0.5
print(1 < 3 > 2)           # True
x = 0
print('양' if x > 0 else '음' if x < 0 else '영')   # 영
print(6 & 1 == 0)          # True
```
