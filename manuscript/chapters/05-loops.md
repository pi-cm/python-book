반 친구 30명의 이름을 출석부에 하나씩 옮겨 적는다고 해 봅시다. 열 명쯤 적으면 손목이 아프고 슬슬 글씨가 엉망이 되죠. 구구단 2단부터 9단까지 72줄을 손으로 쓰는 것도 마찬가지예요. 사람은 똑같은 일을 반복하면 지치고, 지치면 실수합니다.

컴퓨터는 다릅니다. 같은 일을 백 번이든 백만 번이든 지겨워하지도 귀찮아하지도 않고 똑같이 해냅니다. 그러니 반복은 컴퓨터에게 맡기세요. 우리가 반복하지 말아야 할 것은 따로 있습니다. **같은 실수를 쳇바퀴 돌듯 반복하는 것**이요. 오류가 나면 오류 메시지를 읽고, 무엇이 틀렸는지 하나씩 추적해 보세요. 이 장의 예제를 조금씩 바꿔 가며 실행하다 보면 그 습관도 함께 붙습니다.

4장에서 코드의 흐름을 바꾸는 제어문 중 **분기**를 배웠죠. 이번 장은 나머지 하나인 **반복**입니다. 파이썬의 반복문은 두 가지예요.

- **`for`**: 여러 개가 들어 있는 묶음에서 하나씩 차례대로 꺼내며 반복합니다. "출석부의 이름을 처음부터 끝까지 한 명씩."
- **`while`**: 조건이 참인 **동안** 계속 반복합니다. "물이 끓을 때까지 계속 기다리기."

고르는 요령은 간단합니다. 몇 번 반복할지, 무엇을 하나씩 꺼낼지 알면 `for`, 언제 끝날지 미리 알 수 없고 "어떤 상태가 될 때까지"라면 `while`을 씁니다.

## 5.1 for 문 완전정복

### 기본 for 루프 패턴

`for 이름 in 묶음:`이라고 쓰면, 파이썬이 묶음에서 원소를 하나씩 꺼내 `이름`에 넣고 들여쓰기된 코드를 실행합니다. 원소를 다 꺼내면 반복이 끝나요. 4장의 `if`처럼 콜론과 들여쓰기로 "반복할 부분"을 표시합니다. 첫 예제에서 `과일`이라는 변수는 반복할 때마다 `"사과"`, `"바나나"`, … 로 바뀌어 다섯 번 출력됩니다.

반복하다 보면 "지금 몇 번째지?"가 궁금할 때가 많습니다. 이럴 때 쓰는 것이 **`enumerate()`** 예요. 원소마다 번호를 붙여서 `(번호, 원소)` 쌍으로 꺼내 줍니다. 번호는 0부터 시작하지만 `start=1`을 주면 1부터 셀 수 있어요.

여러 묶음을 나란히 함께 돌고 싶을 때는 **`zip()`** 을 씁니다. 옷의 지퍼를 떠올려 보세요. 양쪽 이빨이 하나씩 맞물려 올라가죠? `zip()`도 각 묶음에서 같은 순서의 원소를 하나씩 꺼내 짝을 지어 줍니다. 지퍼가 짧은 쪽 끝에서 멈추듯, `zip()`도 **가장 짧은 묶음이 끝나면 멈춰요**. 긴 쪽 기준으로 끝까지 돌고 싶다면 `itertools.zip_longest()`를 쓰고, 모자란 자리는 `fillvalue`로 채웁니다.

```python
# 1. 기본 반복
과일들 = ["사과", "바나나", "오렌지", "포도", "딸기"]

print("=== 기본 for 루프 ===")
for 과일 in 과일들:
    print(f"맛있는 {과일}!")

# 2. 인덱스와 함께 반복 - enumerate()
print("\n=== enumerate() 활용 ===")
for 순서, 과일 in enumerate(과일들):
    print(f"{순서 + 1}번째: {과일}")

# 시작 인덱스 지정
for 순서, 과일 in enumerate(과일들, start=1):
    print(f"{순서}. {과일}")

# 3. 여러 시퀀스 동시 반복 - zip()
이름들 = ["김철수", "이영희", "박민수"]
나이들 = [25, 30, 35]
직업들 = ["개발자", "디자이너", "기획자"]

print("\n=== zip() 활용 ===")
for 이름, 나이, 직업 in zip(이름들, 나이들, 직업들):
    print(f"{이름}({나이}세) - {직업}")

# 길이가 다른 시퀀스들의 zip
from itertools import zip_longest

긴_리스트 = [1, 2, 3, 4, 5]
짧은_리스트 = ['a', 'b', 'c']

print("\n=== 길이가 다른 시퀀스 처리 ===")
for 숫자, 문자 in zip_longest(긴_리스트, 짧은_리스트, fillvalue='?'):
    print(f"{숫자} - {문자}")
```

`zip_longest` 결과에서 4와 5의 짝이 `?`로 채워진 것을 확인해 보세요. 그냥 `zip()`이었다면 `3 - c`에서 끝났을 겁니다.

그럼 `enumerate`와 `zip`을 섞으면 어떻게 될까요? 아래 코드가 어떻게 출력될지 먼저 생각해 보고 실행해 보세요.

```python
A = [1, 2, 3, 4]
B = ["a", "b", "c"]

for i, (a, b) in enumerate(zip(A, B)):
    print(i, a, b)
```

`0 1 a`, `1 2 b`, `2 3 c` 세 줄이 나옵니다. `B`가 세 개뿐이라 `A`의 4는 짝이 없어서 버려지고요. 여기서 괄호가 중요합니다. `enumerate`는 `(번호, 원소)` 두 개짜리 쌍을 주는데, 그 원소가 또 `zip`이 만든 `(a, b)` 쌍이에요. 즉 `(0, (1, "a"))`처럼 쌍 안에 쌍이 들어 있는 모양입니다. 그래서 받는 쪽도 `i, (a, b)`처럼 같은 모양으로 받아야 해요. 괄호 없이 `for i, a, b in …`이라고 쓰면 "값 세 개를 기대했는데 두 개밖에 없다"는 `ValueError`가 납니다.

### range() 함수 완전 가이드

"1부터 10까지"처럼 숫자를 차례대로 세며 반복하고 싶을 때는 `range()`를 씁니다. 사용법은 세 가지예요.

- `range(5)`: 0부터 **5 직전**까지, 즉 0, 1, 2, 3, 4입니다.
- `range(5, 10)`: 5부터 10 직전까지, 즉 5, 6, 7, 8, 9입니다.
- `range(0, 11, 2)`: 0부터 11 직전까지 2씩 건너뛰며, 즉 0, 2, 4, 6, 8, 10입니다. 간격을 음수로 주면 거꾸로 셉니다.

가장 헷갈리는 점은 **끝 숫자가 포함되지 않는다**는 것입니다. 대신 `range(5)`는 정확히 다섯 번 반복하고, `range(시작, 끝)`의 개수는 `끝 - 시작`으로 바로 계산되니 익숙해지면 오히려 편해요. 인덱스가 0부터 시작하는 리스트와도 딱 맞습니다.

```python
# range() 함수의 모든 형태
print("=== range() 기본 사용법 ===")

# range(stop)
for i in range(5):
    print(f"0부터 4까지: {i}")

# range(start, stop)
print("\n5부터 9까지:")
for i in range(5, 10):
    print(i, end=" ")

# range(start, stop, step)
print("\n\n짝수만:")
for i in range(0, 11, 2):
    print(i, end=" ")

print("\n\n거꾸로 카운트다운:")
for i in range(10, 0, -1):
    print(i, end=" ")

print("\n\n한국어 구구단 (2단):")
단 = 2
for i in range(1, 10):
    print(f"{단} × {i} = {단 * i}")

# range를 리스트로 변환 (메모리 사용 주의)
작은_범위 = list(range(1, 6))
print(f"\n작은 범위 리스트: {작은_범위}")

# 대용량 range는 리스트 변환 금지!
# 큰_범위 = list(range(1000000))  # 메모리 낭비!

# range 객체의 특성
범위 = range(1, 11)
print(f"범위 길이: {len(범위)}")
print(f"5가 범위에 있나? {5 in 범위}")
print(f"범위의 첫 번째: {범위[0]}")
print(f"범위의 마지막: {범위[-1]}")
```

`range`는 숫자를 미리 다 만들어 두지 않습니다. 시작, 끝, 간격 세 숫자만 기억해 두었다가 필요할 때 하나씩 계산해 줘요. 그래서 길이를 묻거나(`len`), 어떤 숫자가 들어 있는지 묻거나(`in`), `[0]`·`[-1]`처럼 위치로 꺼내는 일도 리스트처럼 할 수 있으면서 메모리는 거의 쓰지 않습니다. 이 책의 실행 환경(64비트 파이썬 3.12)에서 `range(1000000)`은 48바이트지만, `list(range(1000000))`로 바꾸면 약 8MB가 됩니다. 예제 주석이 큰 `range`를 리스트로 바꾸지 말라고 한 이유예요.

### 고급 반복 패턴

`for`는 리스트뿐 아니라 하나씩 꺼낼 수 있는 것이면 무엇이든 돌 수 있습니다. 이렇게 `for`로 돌 수 있는 것을 **반복 가능한(iterable) 객체**라고 불러요. 아래 예제는 딕셔너리, 문자열을 돌고, 거꾸로 돌거나(`reversed`) 정렬해서 돌거나(`sorted`) 중복을 빼고 도는 방법을 보여 줍니다.

- **딕셔너리**를 그냥 돌면 **키**가 나옵니다. 값만 원하면 `.values()`, 키와 값을 함께 원하면 `.items()`를 씁니다.
- **문자열**을 돌면 글자가 하나씩 나옵니다. 공백과 쉼표도 한 글자로 세기 때문에 예제의 위치 번호에서 5, 6이 빠져 있어요.
- `sorted()`는 정렬된 **새 리스트**를 만들어 줄 뿐 원본은 그대로 둡니다. 원본 자체를 정렬하는 리스트의 `.sort()` 메서드와는 다르니 6장에서 함께 비교해 보세요.
- 중복을 없애는 두 방법의 결과 순서가 다른 것도 눈여겨보세요. `이미_본_과일` 방식은 처음 나온 순서를 지키고, `set()`은 순서를 기억하지 않아서 예제는 `sorted()`로 가나다순 정렬을 해서 보여 줍니다.

```python
# 1. 딕셔너리 반복의 모든 방법
한국_도시_인구 = {
    "서울": 9720846,
    "부산": 3348871,
    "인천": 2947217,
    "대구": 2427954,
    "광주": 1456468,
    "대전": 1458365
}

print("=== 딕셔너리 반복 패턴 ===")

# 키만 반복
print("도시 목록:")
for 도시 in 한국_도시_인구:  # .keys()와 동일
    print(f"- {도시}")

# 값만 반복
print("\n인구 목록:")
for 인구 in 한국_도시_인구.values():
    print(f"인구: {인구:,}명")

# 키-값 쌍 반복
print("\n도시별 인구:")
for 도시, 인구 in 한국_도시_인구.items():
    print(f"{도시}: {인구:,}명")

# 2. 문자열 반복
한국어_문장 = "안녕하세요, 파이썬!"

print(f"\n=== 문자열 '{한국어_문장}' 문자별 반복 ===")
for i, 문자 in enumerate(한국어_문장):
    if 문자.isalpha():  # 한글/영문자만
        print(f"위치 {i}: '{문자}'")

# 3. 역순 반복 - reversed()
print("\n=== 역순 반복 ===")
숫자들 = [1, 2, 3, 4, 5]
for 숫자 in reversed(숫자들):
    print(숫자, end=" ")

print("\n\n문자열 역순:")
for 문자 in reversed("PYTHON"):
    print(문자, end="")

# 4. 정렬된 반복 - sorted()
무작위_숫자들 = [3, 1, 4, 1, 5, 9, 2, 6]
print(f"\n\n=== 정렬된 반복 ===")
print(f"원본: {무작위_숫자들}")

print("오름차순:")
for 숫자 in sorted(무작위_숫자들):
    print(숫자, end=" ")

print("\n내림차순:")
for 숫자 in sorted(무작위_숫자들, reverse=True):
    print(숫자, end=" ")

# 5. 중복 제거 반복
중복_과일들 = ["사과", "바나나", "사과", "오렌지", "바나나", "포도"]
print(f"\n\n=== 중복 제거 반복 ===")
print(f"원본: {중복_과일들}")

print("중복 제거 (순서 유지):")
이미_본_과일 = set()
for 과일 in 중복_과일들:
    if 과일 not in 이미_본_과일:
        print(과일, end=" ")
        이미_본_과일.add(과일)

print("\n중복 제거 (set 활용):")
for 과일 in sorted(set(중복_과일들)):
    print(과일, end=" ")
```

> **Q. 딕셔너리를 `for 키, 값 in 딕셔너리:`로 돌렸더니 이상한 결과가 나와요.**
> `.items()`를 빠뜨렸기 때문입니다. 딕셔너리를 그냥 돌면 키만 하나씩 나오는데, 그 키를 `키, 값` 두 개로 나눠 담으려고 하니 파이썬은 키 문자열을 글자 단위로 쪼개 버려요. 그래서 `{"서울": 1, "부산": 2}`를 이렇게 돌리면 `서 울`, `부 산`처럼 두 글자 이름이 쪼개져 나오고, 세 글자 이상인 키에서는 `ValueError`가 납니다. 오류 없이 엉뚱한 값이 나오는 경우가 더 무서우니, 키와 값을 함께 꺼낼 때는 꼭 `for 키, 값 in 딕셔너리.items():`라고 쓰세요. 번호까지 붙이려면 `for 번호, (키, 값) in enumerate(딕셔너리.items()):`입니다.

## 5.2 while 문과 무한 루프

### while 루프 기본 패턴

`while`은 말 그대로 "~하는 동안"입니다. `while 조건:` 아래 들여쓴 부분을 조건이 참인 **동안** 계속 반복해요. 반복을 한 번 할 때마다 조건을 다시 확인하고, 거짓이 되는 순간 빠져나갑니다. `for`가 "정해진 묶음을 하나씩 도는" 일정한 반복이라면, `while`은 "어떤 규칙이 지켜지는 동안" 도는 반복이에요. 다른 언어에 있는 `do … while`(일단 한 번 실행하고 조건 확인) 같은 문법은 파이썬에 없습니다.

`while`에서 가장 중요한 것은 **반복 안에서 조건을 언젠가 거짓으로 만드는 무언가가 있어야 한다**는 점입니다. 첫 예제에서는 `카운트 += 1`이 그 역할을 해요. 이 줄을 빼먹으면 `카운트`는 영원히 1이고, `1 <= 5`도 영원히 참이니 반복이 끝나지 않습니다.

아래 예제들을 하나씩 봅시다.

1. 기본형: 1부터 5까지 셉니다.
2. `while True:`는 조건이 항상 참이라 스스로는 멈추지 않는 **무한 반복**입니다. 대신 안쪽에서 "종료"를 받으면 `break`로 빠져나와요. "언제 끝날지는 사용자에게 달린" 프로그램에서 흔히 쓰는 모양입니다. 예제는 실제 `input()` 대신 미리 정해 둔 응답을 차례로 돌려주는 `가짜_입력()`을 씁니다. 함수 안에서 바깥 변수 `응답_인덱스`를 바꾸려고 `global`이라고 선언했어요.
3. `while 숫자_리스트:`는 4장의 "비어 있으면 거짓" 규칙을 쓴 것입니다. `pop(0)`으로 하나씩 꺼내다 보면 리스트가 비고, 빈 리스트는 거짓이라 반복이 끝나요.

### 무한 루프 방지와 안전한 while 문

`while True:`는 쓸모가 많습니다. 사용자가 그만할 때까지 계속 입력을 받는 프로그램, 서버처럼 꺼질 때까지 요청을 기다리는 프로그램, 일정 시간마다 상태를 확인하는 감시 프로그램이 모두 이 모양이에요. 하지만 빠져나오는 길이 막히면 프로그램이 멈추지 않으니, 실무에서는 **안전장치**를 함께 둡니다.

1. **최대 반복 횟수**: `카운터 < 최대_반복`처럼 상한을 둡니다. 원하는 결과를 얻으면 `break`로 일찍 나오고, 상한까지 갔는데도 못 얻으면 `else`에서 알려 줘요(`else`는 5.3절에서 자세히 봅니다).
2. **상태 기계**: "대기 → 작업중 → 완료"처럼 상태가 바뀌어 가다가 "완료"가 되면 멈춥니다. 상태가 꼬여도 무한히 돌지 않게 `총_스텝 < 20`을 함께 걸어 두었어요. `while` 조건 안에서 `상태_전환()`을 부르기 때문에 조건을 확인할 때마다 상태가 한 걸음씩 바뀝니다.
3. **시간 제한**: 정해진 시간이 지나면 멈춥니다. 실제로 몇 초 동안 실행되므로 마지막 줄은 주석으로 막아 두었어요.

```python
# 1. 안전한 카운터 기반 while
def 안전한_카운터_루프(최대_반복=1000):
    """안전장치가 있는 카운터 루프"""
    카운터 = 0
    처리_건수 = 0
    
    while 카운터 < 최대_반복:
        카운터 += 1
        
        # 특정 조건에서만 처리
        if 카운터 % 17 == 0:  # 17의 배수만 처리
            처리_건수 += 1
            print(f"처리: {카운터} (총 {처리_건수}건 처리)")
            
            # 목표 달성 시 조기 종료
            if 처리_건수 >= 5:
                print("목표 달성으로 조기 종료")
                break
    else:
        # while 루프가 break 없이 끝난 경우
        print("최대 반복 횟수에 도달했습니다.")
    
    return 처리_건수

결과 = 안전한_카운터_루프()
print(f"총 {결과}건 처리됨\n")

class 간단한_상태기계:
    def __init__(self):
        self.상태 = "대기"
        self.카운터 = 0
    
    def 상태_전환(self):
        """상태 전환 로직"""
        self.카운터 += 1
        
        if self.상태 == "대기":
            if self.카운터 >= 3:
                self.상태 = "작업중"
                self.카운터 = 0
        elif self.상태 == "작업중":
            if self.카운터 >= 5:
                self.상태 = "완료"
        
        return self.상태 != "완료"

print("=== 상태 기계 시뮬레이션 ===")

print(f"최종 상태: {상태기계.상태}")
```

## 5.3 break, continue, else 절의 고급 활용

### break와 continue 마스터

반복이 도는 도중에 끼어들어 흐름을 바꾸는 보조 제어문이 셋 있습니다. `pass`, `continue`, `break`예요. 하루 세 끼 식사에 비유해 볼게요.

- **`pass`**: 그냥 먹습니다. 아무 일도 하지 않고 하던 대로 계속 갑니다. 문법상 뭔가 써야 하는 자리에 "일단 비워 둠"을 표시할 때 씁니다.
- **`continue`**: 점심은 지금 남긴 채로 끝내고 저녁을 맞이하러 갑니다. 이번 차례의 남은 코드를 건너뛰고 **다음 차례로** 넘어가요.
- **`break`**: 오늘은 더 이상의 식사는 없습니다. 반복 **전체**를 끝내고 빠져나갑니다.

짧은 코드로 직접 확인해 봅시다.

```python
for i in range(20):
    print(f"{i}: 시작")
    if i < 2:
        pass        # 아무 일 없이 아래로 계속
    elif i < 4:
        continue    # 아래 "끝"을 건너뛰고 다음 i로
    else:
        break       # 반복 전체를 끝냄
    print(f"{i}: 끝")
```

0과 1은 `pass`라서 "시작"과 "끝"이 모두 출력됩니다. 2와 3은 `continue`라서 "시작"만 찍히고 "끝"은 건너뛰어요. 4에서 `break`를 만나면 "4: 시작"만 찍고 반복이 통째로 끝나서, `range(20)`인데도 5부터 19까지는 아예 실행되지 않습니다.

아래 예제에서 세 가지 쓰임을 봅시다. `소수_찾기`는 나누어떨어지는 수를 하나라도 찾으면 "소수가 아니다"가 확정되니 더 볼 필요 없이 `break`합니다. `한국어_텍스트_필터링`은 조건에 맞지 않는 텍스트를 만날 때마다 `continue`로 건너뛰어서, 모든 검사를 통과한 텍스트만 맨 아래까지 내려와 처리돼요. 4장에서 본 조기 반환과 같은 생각입니다. `구구단_선택적_출력`은 반복 안에 반복이 있는 **중첩 반복**에서 `break`와 `continue`가 어떻게 동작하는지 보여 줍니다.

```python
# 1. break를 활용한 조기 종료
def 소수_찾기(최대값):
    """지정된 범위에서 소수 찾기 (break 활용)"""
    소수들 = []
    
    for 숫자 in range(2, 최대값 + 1):
        소수인가 = True
        
        # 2부터 숫자의 제곱근까지만 확인 (최적화)
        for 나누는_수 in range(2, int(숫자 ** 0.5) + 1):
            if 숫자 % 나누는_수 == 0:
                소수인가 = False
                break  # 소수가 아니면 더 이상 확인할 필요 없음
        
        if 소수인가:
            소수들.append(숫자)
    
    return 소수들

print("=== break 활용: 소수 찾기 ===")
소수_목록 = 소수_찾기(30)
print(f"30 이하의 소수: {소수_목록}")

# 2. continue를 활용한 선택적 처리
def 한국어_텍스트_필터링(텍스트_목록):
    """한국어가 포함된 텍스트만 처리 (continue 활용)"""
    처리된_텍스트들 = []
    
    for 텍스트 in 텍스트_목록:
        # 빈 문자열 건너뛰기
        if not 텍스트.strip():
            continue
        
        # 한국어 문자가 없으면 건너뛰기
        한국어_포함 = any('\uac00' <= 문자 <= '\ud7a3' for 문자 in 텍스트)
        if not 한국어_포함:
            continue
        
        # 너무 짧거나 긴 텍스트 건너뛰기
        if len(텍스트) < 2 or len(텍스트) > 100:
            continue
        
        # 모든 조건을 통과한 텍스트만 처리
        처리된_텍스트 = 텍스트.strip().upper()
        처리된_텍스트들.append(처리된_텍스트)
    
    return 처리된_텍스트들

텍스트_예제들 = [
    "안녕하세요",
    "",
    "Hello World",
    "파이썬 프로그래밍",
    "Python",
    "한국어와 English 혼합",
    "가"
]

print("\n=== continue 활용: 한국어 텍스트 필터링 ===")
print(f"원본 텍스트: {텍스트_예제들}")
필터링_결과 = 한국어_텍스트_필터링(텍스트_예제들)
print(f"필터링 결과: {필터링_결과}")

# 3. 중첩 루프에서 break/continue
def 구구단_선택적_출력(시작단=2, 끝단=9):
    """특정 조건의 구구단만 출력"""
    print("=== 선택적 구구단 출력 ===")
    
    for 단 in range(시작단, 끝단 + 1):
        # 홀수 단만 출력
        if 단 % 2 == 0:
            continue
        
        print(f"\n{단}단:")
        
        for 곱 in range(1, 10):
            결과 = 단 * 곱
            
            # 결과가 50 이상이면 해당 단 중단
            if 결과 >= 50:
                print(f"  (50 이상이므로 {단}단 중단)")
                break
            
            print(f"  {단} × {곱} = {결과}")

구구단_선택적_출력()
```

구구단 결과를 보면 7단은 `7 × 7 = 49`까지 출력하고 다음 결과가 56이라 멈춥니다. 그런데 프로그램 전체가 끝나지 않고 9단이 이어서 출력되죠? **`break`는 자신을 감싸고 있는 가장 안쪽 반복 하나만 끝냅니다.** 오늘의 식사가 끝나도 내일의 식사는 또 찾아오는 것처럼요. 바깥 반복의 `continue`도 마찬가지로 바깥 반복의 다음 차례(다음 단)로 넘어갑니다.

> **Q. 그러면 여러 겹의 반복문에서 한 번에 밖으로 나가는 방법은 없나요?**
> 있습니다. 중첩 반복을 함수 안에 넣고, 빠져나가고 싶은 순간에 `return`하면 됩니다. `return`은 반복이 몇 겹이든 함수 자체를 끝내 버리니까요. 5.5절의 `매트릭스_특정값_찾기_기본`이 바로 이 방법으로, 2차원 표에서 값을 찾자마자 `return (i, j)`로 두 겹의 반복을 한 번에 빠져나옵니다.

### else 절의 특별한 활용

파이썬의 `for`와 `while`에는 `else`를 붙일 수 있습니다. 반복문에 웬 `else`일까 싶죠? 이 `else`는 **반복이 `break` 없이 끝까지 돌았을 때만** 실행됩니다. 중간에 `break`로 빠져나오면 건너뛰어요.

"찾기"에 쓰면 뜻이 분명해집니다. 서랍을 하나씩 열며 열쇠를 찾다가 찾으면 `break`, 마지막 서랍까지 다 열었는데도 `break`가 한 번도 없었다면 `else`에서 "못 찾았다"고 말하는 거예요. 그래서 반복문의 `else`는 "그렇지 않으면"보다 **"중간에 멈추지 않았다면"** 으로 읽는 편이 정확합니다. 아래 `타겟_찾기`와 `소수_판별_with_else`가 그 전형적인 모양이에요. 소수 판별에서는 나누어떨어지는 수를 찾으면 `break`하고, 끝까지 못 찾으면 `else`에서 "소수입니다"를 출력합니다.

```python
# 1. 비교용: break가 없으면 else도 필요 없다
def 완전수_찾기(최대값):
    """완전수 찾기 (안쪽 반복에 break가 없으므로 else 없이 쓴다)"""
    완전수들 = []
    
    for 숫자 in range(1, 최대값 + 1):
        약수_합 = 0
        
        # 자기 자신을 제외한 약수들의 합 계산
        for 나누는_수 in range(1, 숫자):
            if 숫자 % 나누는_수 == 0:
                약수_합 += 나누는_수
        
        # 안쪽 반복이 다 끝난 뒤 약수의 합을 확인
        if 약수_합 == 숫자:
            완전수들.append(숫자)
    
    return 완전수들

print("=== 완전수 찾기 ===")
완전수_목록 = 완전수_찾기(30)
print(f"30 이하의 완전수: {완전수_목록}")

# 2. while-else: 조건으로 종료된 경우
def 타겟_찾기(리스트, 타겟):
    """리스트에서 타겟 값 찾기 (while-else 활용)"""
    인덱스 = 0
    
    while 인덱스 < len(리스트):
        if 리스트[인덱스] == 타겟:
            print(f"타겟 '{타겟}'을 인덱스 {인덱스}에서 발견!")
            break
        인덱스 += 1
    else:
        # while 조건이 False가 되어 종료됨 (break로 종료되지 않음)
        print(f"타겟 '{타겟}'을 찾지 못했습니다.")
    
    return 인덱스 if 인덱스 < len(리스트) else -1

한국_도시들 = ["서울", "부산", "대구", "인천", "광주", "대전", "울산"]

print("\n=== while-else 활용: 타겟 찾기 ===")
타겟_찾기(한국_도시들, "광주")  # 찾을 수 있는 경우
타겟_찾기(한국_도시들, "제주")  # 찾을 수 없는 경우

# 3. 복잡한 조건에서 else 절 활용
def 소수_판별_with_else(숫자):
    """소수 판별 (else 절로 결과 처리)"""
    if 숫자 < 2:
        return False
    
    for 나누는_수 in range(2, int(숫자 ** 0.5) + 1):
        if 숫자 % 나누는_수 == 0:
            print(f"{숫자}는 {나누는_수}로 나누어지므로 소수가 아닙니다.")
            break
    else:
        # for 루프가 break 없이 끝남 = 소수임
        print(f"{숫자}는 소수입니다!")
        return True
    
    return False

print("\n=== for-else 활용: 소수 판별 ===")
테스트_숫자들 = [17, 21, 23, 25, 29]
for 숫자 in 테스트_숫자들:
    소수_판별_with_else(숫자)
```

첫 번째 `완전수_찾기`는 비교를 위해 넣은 예제입니다. 안쪽 반복에 `break`가 하나도 없죠? 이럴 때 `else`를 붙이면 매번 실행되니 "안쪽 반복이 다 끝난 뒤에"라는 뜻밖에 안 됩니다. 그래서 `else` 없이 반복문 바로 아래에 약수의 합을 확인하는 코드를 썼어요. 반복문의 `else`는 `break`와 짝을 이룰 때 비로소 의미가 생깁니다. 결과로 나온 6(= 1 + 2 + 3)과 28(= 1 + 2 + 4 + 7 + 14)은 자기 자신을 뺀 약수를 모두 더하면 자기 자신이 되는 수, 즉 완전수입니다.

## 5.4 컴프리헨션 완전 마스터

### 리스트 컴프리헨션 심화

반복문으로 새 리스트를 만드는 일은 정말 자주 합니다. 빈 리스트를 만들고, `for`로 돌면서, 조건을 확인하고, `append()`로 하나씩 넣죠. 네 줄짜리 이 작업을 한 줄로 줄인 문법이 **리스트 컴프리헨션**입니다.

`[x for x in 반복가능객체 if 조건]`은 "반복 가능한 객체의 모든 원소 중에서 `if` 뒤의 조건을 만족하는 원소를 모아 새 리스트를 만든다"는 뜻이에요. 읽을 때는 가운데 `for` 부분부터 읽으세요. "숫자들에서 `x`를 하나씩 꺼내서 → (조건이 있으면) 짝수인 것만 골라 → 맨 앞의 `x**2`로 바꿔 담는다." 맨 앞의 식이 "무엇을 담을지", `for`가 "어디서 꺼낼지", `if`가 "어떤 것만 남길지"입니다.

4장에서 봤듯이 `if`의 위치에 따라 뜻이 다르니 주의하세요. `for` 뒤의 `if`는 걸러내기, `for` 앞의 `값1 if 조건 else 값2`는 원소마다 값을 고르는 조건부 표현식입니다.

`for`를 두 번 쓰는 **중첩 컴프리헨션**도 있습니다. 순서는 일반 중첩 반복문을 그대로 한 줄로 편 것과 같아요. `[항목 for 서브리스트 in 중첩_리스트 for 항목 in 서브리스트]`는 바깥 `for 서브리스트 in 중첩_리스트:` 안에 `for 항목 in 서브리스트:`가 들어 있는 모양을 왼쪽부터 쓴 것입니다. 반면 구구단 표처럼 `[[…] for 단 in …]`으로 대괄호 안에 대괄호를 넣으면, 리스트 안에 리스트가 들어 있는 2차원 리스트가 만들어집니다.

```python
# 1. 기본 리스트 컴프리헨션
숫자들 = range(1, 11)

# 기본 형태: [표현식 for 항목 in 반복가능객체]
제곱들 = [x**2 for x in 숫자들]
print(f"제곱들: {제곱들}")

# 조건이 있는 형태: [표현식 for 항목 in 반복가능객체 if 조건]
짝수_제곱들 = [x**2 for x in 숫자들 if x % 2 == 0]
print(f"짝수 제곱들: {짝수_제곱들}")

# 복잡한 표현식
한국어_숫자들 = [f"{x}번째" for x in range(1, 6)]
print(f"한국어 숫자들: {한국어_숫자들}")

# 2. 조건부 표현식이 있는 컴프리헨션
# 형태: [참_표현식 if 조건 else 거짓_표현식 for 항목 in 반복가능객체]
분류된_숫자들 = [f"{x}(짝)" if x % 2 == 0 else f"{x}(홀)" for x in range(1, 11)]
print(f"분류된 숫자들: {분류된_숫자들}")

# 3. 중첩된 리스트 컴프리헨션
# 2차원 리스트 생성
구구단_표 = [[단 * 곱 for 곱 in range(1, 10)] for 단 in range(2, 10)]
print("구구단 표 (2-9단):")
for i, 단_결과 in enumerate(구구단_표, 2):
    print(f"{i}단: {단_결과}")

# 중첩 리스트 평탄화
중첩_리스트 = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
평탄화된_리스트 = [항목 for 서브리스트 in 중첩_리스트 for 항목 in 서브리스트]
print(f"\n중첩 리스트: {중첩_리스트}")
print(f"평탄화된 리스트: {평탄화된_리스트}")

# 4. 문자열 처리 컴프리헨션
한국어_문장 = "안녕하세요 파이썬 프로그래밍 세계에 오신 것을 환영합니다"
단어들 = 한국어_문장.split()

# 긴 단어만 선택
긴_단어들 = [단어 for 단어 in 단어들 if len(단어) >= 3]
print(f"\n긴 단어들 (3글자 이상): {긴_단어들}")

# 단어 길이 정보
단어_길이_정보 = [f"{단어}({len(단어)}글자)" for 단어 in 단어들]
print(f"단어 길이 정보: {단어_길이_정보}")

# 한글만 추출
텍스트 = "Hello 안녕하세요 123 Python 파이썬 !!!"
한글_문자들 = [문자 for 문자 in 텍스트 if '\uac00' <= 문자 <= '\ud7a3']
print(f"한글 문자들: {''.join(한글_문자들)}")
```

마지막 예제의 `'가' <= 문자 <= '힣'`는 3장의 연쇄 비교와 문자열 비교를 함께 쓴 것입니다. `가`은 "가", `힣`은 "힣"의 유니코드 번호라서, 이 범위에 들어가는 글자는 완성된 한글 한 글자예요. 그래서 영어와 숫자, 느낌표는 빠지고 `안녕하세요파이썬`만 남습니다.

컴프리헨션은 짧고 빠르지만 만능은 아닙니다. 한 줄에 `for`와 `if`가 서너 개씩 엉키면 읽기가 오히려 어려워져요. 한눈에 안 읽히면 그냥 `for` 반복문으로 풀어 쓰세요. 그게 다음 날의 나를 돕는 길입니다.

### 딕셔너리 컴프리헨션

대괄호 대신 중괄호를 쓰고, 앞의 식을 `키: 값` 모양으로 쓰면 딕셔너리가 만들어집니다. `{x: x**2 for x in 숫자들}`은 "숫자 `x`를 키로, 그 제곱을 값으로" 담은 딕셔너리예요. 기존 딕셔너리를 바꿀 때는 `.items()`로 키와 값을 함께 꺼내 쓰는 것이 기본입니다.

```python
# 1. 기본 딕셔너리 컴프리헨션
숫자들 = range(1, 6)
제곱_딕셔너리 = {x: x**2 for x in 숫자들}
print(f"제곱 딕셔너리: {제곱_딕셔너리}")

# 2. 기존 딕셔너리 변형
원본_점수 = {"국어": 85, "영어": 92, "수학": 78, "과학": 88, "사회": 90}

# 등급 변환
def 점수_to_등급(점수):
    if 점수 >= 90: return "A"
    elif 점수 >= 80: return "B" 
    elif 점수 >= 70: return "C"
    else: return "F"

등급_딕셔너리 = {과목: 점수_to_등급(점수) for 과목, 점수 in 원본_점수.items()}
print(f"\n점수: {원본_점수}")
print(f"등급: {등급_딕셔너리}")

# 조건부 필터링
우수_과목들 = {과목: 점수 for 과목, 점수 in 원본_점수.items() if 점수 >= 85}
print(f"우수 과목들 (85점 이상): {우수_과목들}")

# 3. 복잡한 딕셔너리 컴프리헨션
학생_정보_목록 = [
    {"이름": "김철수", "나이": 20, "학과": "컴퓨터공학"},
    {"이름": "이영희", "나이": 22, "학과": "전자공학"},
    {"이름": "박민수", "나이": 19, "학과": "컴퓨터공학"},
    {"이름": "최지은", "나이": 21, "학과": "기계공학"}
]

# 이름을 키로 하는 나이 딕셔너리
이름별_나이 = {학생["이름"]: 학생["나이"] for 학생 in 학생_정보_목록}
print(f"\n이름별 나이: {이름별_나이}")

# 학과별 학생 수
학과별_학생수 = {}
for 학생 in 학생_정보_목록:
    학과 = 학생["학과"]
    학과별_학생수[학과] = 학과별_학생수.get(학과, 0) + 1

print(f"학과별 학생 수: {학과별_학생수}")

# 컴프리헨션으로 학과별 학생 이름 리스트
from collections import defaultdict
학과별_학생들 = defaultdict(list)
for 학생 in 학생_정보_목록:
    학과별_학생들[학생["학과"]].append(학생["이름"])

학과별_이름_딕셔너리 = {학과: 이름들 for 학과, 이름들 in 학과별_학생들.items()}
print(f"학과별 학생 이름: {학과별_이름_딕셔너리}")

# 4. 키와 값 변환
영한_딕셔너리 = {"apple": "사과", "banana": "바나나", "orange": "오렌지"}
한영_딕셔너리 = {한글: 영어 for 영어, 한글 in 영한_딕셔너리.items()}
print(f"\n영한: {영한_딕셔너리}")
print(f"한영: {한영_딕셔너리}")
```

`학과별_학생수`는 컴프리헨션 대신 일반 `for` 반복문으로 셌습니다. "이미 센 개수에 1을 더하는" 일은 앞 원소의 결과를 이어받아야 해서 컴프리헨션 한 줄로 쓰기 어렵거든요. `.get(학과, 0)`은 처음 보는 학과면 0에서 출발하게 해 줍니다. 그 아래의 `defaultdict(list)`는 처음 보는 키에 자동으로 빈 리스트를 만들어 주는 딕셔너리인데, 7장에서 자세히 다룹니다.

마지막 예제는 키와 값을 뒤집습니다. 이때 값이 겹치면 조심하세요. 딕셔너리의 키는 중복될 수 없어서, 서로 다른 두 키가 같은 값을 갖고 있었다면 뒤집은 결과에는 나중에 나온 것 하나만 남습니다.

### 셋 컴프리헨션

중괄호를 쓰되 `키: 값`이 아니라 값 하나만 쓰면 **집합(set)** 이 만들어집니다. 집합은 같은 원소를 두 번 담지 않으니, 예제처럼 `[1, 2, 2, 3, 3, 3, …]`을 제곱해도 결과에는 서로 다른 값만 남아요. 집합에 대해서는 7장에서 자세히 배웁니다.

```python
# 1. 기본 셋 컴프리헨션
숫자들 = [1, 2, 2, 3, 3, 3, 4, 4, 5]
유니크_제곱들 = {x**2 for x in 숫자들}
print(f"원본 (중복 포함): {숫자들}")
```

### 제너레이터 표현식

리스트 컴프리헨션의 대괄호를 소괄호로 바꾸면 **제너레이터 표현식**이 됩니다. 모양은 거의 같은데 동작이 완전히 달라요. 리스트 컴프리헨션은 값을 **한꺼번에 전부** 만들어 메모리에 쌓아 두고, 제너레이터는 값을 달라고 할 때마다 **하나씩** 만들어 줍니다.

회전초밥집을 떠올려 보세요. 리스트는 주문한 초밥 100접시를 한꺼번에 식탁에 깔아 두는 것이고, 제너레이터는 먹을 때마다 한 접시씩 만들어 레일에 올려 주는 것입니다. 식탁이 좁아도(메모리가 적어도) 얼마든지 먹을 수 있죠. 대신 지나간 접시는 다시 돌아오지 않습니다. **제너레이터는 한 번 다 꺼내면 끝**이라, 예제의 `제너레이터_제곱`을 `for`로 한 번 돈 뒤에 다시 돌면 아무것도 나오지 않아요.

예제를 출력해 보면 리스트는 값이 바로 보이지만 제너레이터는 `<generator object …>`라는 이름표만 보입니다. 아직 아무 값도 만들지 않았다는 뜻이에요. `큰_수_제너레이터`처럼 함수 안에 `yield`를 쓰면 함수도 제너레이터가 되는데, 이건 15장에서 자세히 배웁니다. `sum()`, `max()`처럼 값을 하나씩 받아 처리하는 함수에는 `sum(x**2 for x in …)`처럼 괄호를 하나 생략하고 바로 넣을 수 있어요.

## 5.5 중첩 루프 최적화와 성능 향상

### 중첩 루프 최적화 기법

반복 안에 반복을 넣으면 실행 횟수가 곱으로 늘어납니다. 100개짜리 리스트 두 개를 이중 반복으로 비교하면 100 × 100 = 1만 번, 1,000개씩이면 100만 번이에요. 이렇게 입력 크기 n, m의 곱만큼 일하는 것을 O(n×m)이라고 표기합니다. 데이터가 열 배 커지면 일은 백 배가 되는 셈이죠.

`효율적_중복_찾기`는 이 곱셈을 덧셈으로 바꿉니다. 두 번째 리스트를 먼저 한 번 훑어서 딕셔너리로 만들어 두면(m번), 첫 번째 리스트의 각 값이 거기 있는지는 딕셔너리에 바로 물어볼 수 있거든요(n번). 사전에서 단어를 찾을 때 첫 쪽부터 넘기지 않고 가나다 색인으로 바로 펼치는 것과 같습니다. 딕셔너리의 `in`이 왜 빠른지는 7장에서 다룹니다.

```python
import time
from typing import List, Tuple

# 1. 비효율적 vs 효율적 중첩 루프
def 비효율적_중복_찾기(리스트1: List[int], 리스트2: List[int]) -> List[Tuple[int, int]]:
    """비효율적인 중복 찾기 O(n*m)"""
    중복들 = []
    for i, 값1 in enumerate(리스트1):
        for j, 값2 in enumerate(리스트2):
            if 값1 == 값2:
                중복들.append((i, j))
    return 중복들

def 효율적_중복_찾기(리스트1: List[int], 리스트2: List[int]) -> List[Tuple[int, int]]:
    """효율적인 중복 찾기 O(n+m)"""
    # 두 번째 리스트를 딕셔너리로 변환 (O(m))
    값_to_인덱스들 = {}
    for j, 값 in enumerate(리스트2):
        if 값 not in 값_to_인덱스들:
            값_to_인덱스들[값] = []
        값_to_인덱스들[값].append(j)
    
    # 첫 번째 리스트를 순회하며 찾기 (O(n))
    중복들 = []
    for i, 값 in enumerate(리스트1):
        if 값 in 값_to_인덱스들:
            for j in 값_to_인덱스들[값]:
                중복들.append((i, j))
    
    return 중복들

# 성능 비교
큰_리스트1 = list(range(0, 1000, 2))  # 짝수
큰_리스트2 = list(range(0, 1000, 3))  # 3의 배수

print("=== 중첩 루프 최적화 성능 비교 ===")

# 비효율적 방법
시작 = time.time()
결과1 = 비효율적_중복_찾기(큰_리스트1[:100], 큰_리스트2[:100])
시간1 = time.time() - 시작

# 효율적 방법  
시작 = time.time()
결과2 = 효율적_중복_찾기(큰_리스트1[:100], 큰_리스트2[:100])
시간2 = time.time() - 시작

print(f"비효율적 방법: {시간1:.4f}초, 결과 수: {len(결과1)}")
print(f"효율적 방법: {시간2:.4f}초, 결과 수: {len(결과2)}")
print(f"성능 개선: {시간1/시간2:.2f}배 빠름" if 시간2 > 0 else "측정 불가")

# 2. 조기 종료 최적화
def 매트릭스_특정값_찾기_기본(매트릭스: List[List[int]], 타겟: int) -> Tuple[int, int]:
    """기본적인 2차원 배열 검색"""
    for i in range(len(매트릭스)):
        for j in range(len(매트릭스[i])):
            if 매트릭스[i][j] == 타겟:
                return (i, j)
    return (-1, -1)

def 매트릭스_특정값_찾기_최적화(매트릭스: List[List[int]], 타겟: int) -> Tuple[int, int]:
    """최적화된 2차원 배열 검색 (조기 종료)"""
    for i, 행 in enumerate(매트릭스):
        for j, 값 in enumerate(행):
            if 값 == 타겟:
                return (i, j)
            # 정렬된 배열이라면 추가 최적화 가능
            # if 값 > 타겟:
            #     break
    return (-1, -1)

# 3. 루프 언롤링 (Loop Unrolling)
def 기본_합계_계산(숫자들: List[int]) -> int:
    """기본적인 합계 계산"""
    합계 = 0
    for 숫자 in 숫자들:
        합계 += 숫자
    return 합계

def 언롤링_합계_계산(숫자들: List[int]) -> int:
    """루프 언롤링을 적용한 합계 계산"""
    합계 = 0
    i = 0
    
    # 4개씩 묶어서 처리
    while i + 3 < len(숫자들):
        합계 += 숫자들[i] + 숫자들[i+1] + 숫자들[i+2] + 숫자들[i+3]
        i += 4
    
    # 나머지 처리
    while i < len(숫자들):
        합계 += 숫자들[i]
        i += 1
    
    return 합계

# 테스트
테스트_숫자들 = list(range(1, 10001))

시작 = time.time()
결과1 = 기본_합계_계산(테스트_숫자들)
시간1 = time.time() - 시작

시작 = time.time()
결과2 = 언롤링_합계_계산(테스트_숫자들)
시간2 = time.time() - 시작

print(f"\n=== 루프 언롤링 비교 ===")
print(f"기본 방법: {결과1}, 시간: {시간1:.6f}초")
print(f"언롤링 방법: {결과2}, 시간: {시간2:.6f}초")
```

시간 측정 결과는 컴퓨터마다, 실행할 때마다 달라집니다. 특히 `time.time()`으로 아주 짧은 작업을 딱 한 번 재면 오차가 커서, 100개 정도의 작은 데이터에서는 효율적 방법이 오히려 느리게 찍히기도 해요. 제대로 비교하려면 `timeit` 모듈로 여러 번 반복해 재야 합니다. 이 책의 실행 환경에서 `timeit`으로 각각 20번씩 재 보니, 100개일 때 딕셔너리 방법이 약 15배, 500개일 때 약 60배 빨랐습니다. 데이터가 커질수록 차이가 벌어지는 것이 O(n×m)과 O(n+m)의 차이예요.

두 번째 기법인 **조기 종료**는 찾는 값을 만나자마자 `return`해서 남은 반복을 모두 생략합니다. 앞의 Q&A에서 본 "여러 겹의 반복을 한 번에 빠져나가기"이기도 하죠.

세 번째 **루프 언롤링**은 반복 한 번에 원소 네 개씩 처리해서 반복 횟수를 줄이는 기법입니다. C 같은 언어에서는 쓰이지만 파이썬에서는 기대만큼 효과가 없어요. 같은 환경에서 `timeit`으로 재 보니 언롤링 버전이 기본 반복문보다 오히려 두 배쯤 느렸고, 내장 함수 `sum()`은 기본 반복문보다 네 배 넘게 빨랐습니다. 파이썬에서는 **직접 반복문을 짜기 전에 같은 일을 하는 내장 함수가 있는지 먼저 찾아보는 것**이 가장 확실한 최적화입니다.

### 메모리 효율적인 루프 패턴

데이터가 메모리에 다 들어가지 않을 만큼 크면 어떻게 할까요? 이삿짐을 한 번에 다 들 수 없으면 상자에 나눠 담아 여러 번 나르죠. 아래 세 패턴은 모두 "한꺼번에 하지 말고 나눠서, 또는 한 번 한 일은 다시 하지 않기"라는 생각에서 나왔습니다.

1. **청크 단위 처리**: `range(0, len(데이터), 청크_크기)`로 1,000칸씩 건너뛰며 `데이터[i:i + 청크_크기]`만큼 잘라서 처리합니다.
2. **한 줄씩 처리**: 파일을 통째로 읽지 않고 한 줄씩 읽으며 필요한 것만 셉니다. 예제는 실제 파일 대신 리스트로 흉내 냈어요. 실제 파일을 한 줄씩 읽는 방법은 12장에서 배웁니다.
3. **캐싱**: 한 번 계산한 결과를 딕셔너리에 저장해 두고, 같은 질문이 오면 다시 계산하지 않고 꺼내 줍니다.

```python
# 1. 큰 데이터셋 처리 - 청크 단위 처리
def 청크_단위_처리(데이터, 청크_크기=1000):
    """큰 데이터를 청크 단위로 처리"""
    처리된_개수 = 0
    
    for i in range(0, len(데이터), 청크_크기):
        청크 = 데이터[i:i + 청크_크기]
        
        # 청크 처리 (예: 각 값에 2를 곱함)
        처리된_청크 = [값 * 2 for 값 in 청크]
        처리된_개수 += len(처리된_청크)
        
        print(f"청크 {i//청크_크기 + 1} 처리 완료: {len(처리된_청크)}개 항목")

        if n in self.캐시:
            return self.캐시[n]

        return self.캐시[n]
```

## 실습 프로젝트: 한국어 텍스트 분석 시스템

이번 장의 반복 기법을 모아 한국어 글을 분석하는 프로그램을 만들어 봅시다. 글을 넣으면 문장 수, 단어 빈도, 문자 구성, 문체를 알려 줍니다. 처음 보는 도구가 몇 가지 나오는데, 역할만 알고 넘어가도 충분해요.

- `re`는 정규표현식 모듈로, "한글이 한 글자 이상 이어진 부분"(`[가-힣]+`) 같은 글자 패턴을 찾거나 바꿉니다. 17장에서 한글 처리와 함께 자세히 다룹니다.
- `Counter`는 원소별 개수를 세어 주는 딕셔너리이고, `.most_common(10)`은 가장 많이 나온 10개를 돌려줍니다. `defaultdict(int)`는 처음 보는 키를 0으로 시작해 주는 딕셔너리예요. 둘 다 7장과 8장에서 다시 만납니다.

반복문이 쓰인 곳을 찾아보세요. `특성_분석`은 글자를 하나씩 돌며 `if-elif`로 한글·영어·숫자·문장부호·공백을 나눠 세고, `문체_분석`은 문장을 하나씩 돌며 어미를 보고 분류합니다. `단어_추출`은 반복하면서 `extend()`로 모으고, `문장_분리`는 컴프리헨션으로 빈 문장을 걸러 내요.

```python
import re
from collections import Counter, defaultdict
from typing import Dict, List, Tuple
import time

class 한국어텍스트분석기:
    """한국어 텍스트를 종합적으로 분석하는 시스템"""
    
    def __init__(self):
        self.조사_목록 = {'이', '가', '을', '를', '에', '의', '로', '으로', '에서', '와', '과', '도', '만', '까지', '부터'}
        self.어미_패턴 = re.compile(r'(다|요|니다|습니다|세요|ㅂ니다)$')
        self.한글_패턴 = re.compile(r'[가-힣]+')
        
    def 텍스트_전처리(self, 텍스트: str) -> str:
        """텍스트 전처리 및 정규화"""
        # 불필요한 공백 제거
        텍스트 = re.sub(r'\s+', ' ', 텍스트.strip())
        
        # 특수문자 정리 (한글, 영어, 숫자, 기본 문장부호만 유지)
        텍스트 = re.sub(r'[^\w\s가-힣.,!?]', '', 텍스트)
        
        return 텍스트
    
    def 문장_분리(self, 텍스트: str) -> List[str]:
        """문장 단위로 분리"""
        # 한국어 문장 끝 패턴
        문장_패턴 = re.compile(r'[.!?]+\s*')
        문장들 = 문장_패턴.split(텍스트)
        
        # 빈 문장 제거 및 정리
        return [문장.strip() for 문장 in 문장들 if 문장.strip()]
    
    def 단어_추출(self, 텍스트: str) -> List[str]:
        """한글 단어만 추출 (간단한 공백 기반 분리)"""
        단어들 = []
        
        # 공백으로 분리 후 한글만 필터링
        for 토큰 in 텍스트.split():
            한글_매치 = self.한글_패턴.findall(토큰)
            단어들.extend(한글_매치)
        
        # 조사 제거 (간단한 방식)
        정제된_단어들 = []
        for 단어 in 단어들:
            if len(단어) > 1 and 단어 not in self.조사_목록:
                정제된_단어들.append(단어)
        
        return 정제된_단어들
    
    def 빈도_분석(self, 단어들: List[str], 상위_N: int = 10) -> List[Tuple[str, int]]:
        """단어 빈도 분석"""
        빈도_카운터 = Counter(단어들)
        return 빈도_카운터.most_common(상위_N)
    
    def 문장_길이_분석(self, 문장들: List[str]) -> Dict[str, float]:
        """문장 길이 통계"""
        if not 문장들:
            return {"평균": 0, "최대": 0, "최소": 0}
        
        길이들 = [len(문장) for 문장 in 문장들]
        
        return {
            "평균": sum(길이들) / len(길이들),
            "최대": max(길이들),
            "최소": min(길이들),
            "총_문장수": len(문장들)
        }
    
    def 특성_분석(self, 텍스트: str) -> Dict[str, int]:
        """텍스트 특성 분석"""
        특성들 = defaultdict(int)
        
        for 문자 in 텍스트:
            if '\uac00' <= 문자 <= '\ud7a3':  # 한글
                특성들['한글'] += 1
            elif 문자.isalpha():  # 영어
                특성들['영어'] += 1
            elif 문자.isdigit():  # 숫자
                특성들['숫자'] += 1
            elif 문자 in '.,!?':  # 문장부호
                특성들['문장부호'] += 1
            elif 문자.isspace():  # 공백
                특성들['공백'] += 1
            else:  # 기타
                특성들['기타'] += 1
        
        return dict(특성들)
    
    def 종성_분석(self, 단어들: List[str]) -> Dict[str, int]:
        """단어 끝 글자(종성) 분석"""
        종성_카운터 = Counter()
        
        for 단어 in 단어들:
            if 단어 and '\uac00' <= 단어[-1] <= '\ud7a3':
                종성_카운터[단어[-1]] += 1
        
        return dict(종성_카운터.most_common(10))
    
    def 문체_분석(self, 문장들: List[str]) -> Dict[str, int]:
        """문체 패턴 분석"""
        문체_패턴 = defaultdict(int)
        
        for 문장 in 문장들:
            if re.search(r'습니다|ㅂ니다', 문장):
                문체_패턴['격식체'] += 1
            elif re.search(r'해요|세요|어요|아요', 문장):
                문체_패턴['해요체'] += 1
            elif re.search(r'한다|된다|이다', 문장):
                문체_패턴['해라체'] += 1
            elif '?' in 문장:
                문체_패턴['의문문'] += 1
            elif '!' in 문장:
                문체_패턴['감탄문'] += 1
            else:
                문체_패턴['평서문'] += 1
        
        return dict(문체_패턴)
    
    def 종합_분석(self, 텍스트: str) -> Dict:
        """텍스트 종합 분석"""
        시작_시간 = time.time()
        
        # 전처리
        정제된_텍스트 = self.텍스트_전처리(텍스트)
        
        # 문장 분리
        문장들 = self.문장_분리(정제된_텍스트)
        
        # 단어 추출
        단어들 = self.단어_추출(정제된_텍스트)
        
        # 각종 분석 수행
        분석_결과 = {
            "기본_정보": {
                "원본_길이": len(텍스트),
                "정제_후_길이": len(정제된_텍스트),
                "총_문장_수": len(문장들),
                "총_단어_수": len(단어들),
                "유니크_단어_수": len(set(단어들))
            },
            "빈도_분석": self.빈도_분석(단어들, 10),
            "문장_길이": self.문장_길이_분석(문장들),
            "문자_특성": self.특성_분석(정제된_텍스트),
            "종성_분석": self.종성_분석(단어들),
            "문체_분석": self.문체_분석(문장들),
            "처리_시간": time.time() - 시작_시간
        }
        
        return 분석_결과
    
    def 결과_출력(self, 분석_결과: Dict):
        """분석 결과를 보기 좋게 출력"""
        print("=" * 60)
        print("한국어 텍스트 분석 결과")
        print("=" * 60)
        
        # 기본 정보
        기본_정보 = 분석_결과["기본_정보"]
        print(f"\n기본 정보:")
        print(f"  • 원본 길이: {기본_정보['원본_길이']:,}자")
        print(f"  • 정제 후 길이: {기본_정보['정제_후_길이']:,}자")
        print(f"  • 총 문장 수: {기본_정보['총_문장_수']:,}개")
        print(f"  • 총 단어 수: {기본_정보['총_단어_수']:,}개")
        print(f"  • 유니크 단어 수: {기본_정보['유니크_단어_수']:,}개")
        
        # 빈도 분석
        print(f"\n단어 빈도 TOP 10:")
        for 순위, (단어, 빈도) in enumerate(분석_결과["빈도_분석"], 1):
            print(f"  {순위:2d}. {단어} ({빈도}회)")
        
        # 문장 길이 통계
        문장_통계 = 분석_결과["문장_길이"]
        print(f"\n문장 길이 통계:")
        print(f"  • 평균 길이: {문장_통계['평균']:.1f}자")
        print(f"  • 최대 길이: {문장_통계['최대']}자")
        print(f"  • 최소 길이: {문장_통계['최소']}자")
        
        # 문자 특성
        문자_특성 = 분석_결과["문자_특성"]
        전체_문자수 = sum(문자_특성.values())
        print(f"\n문자 구성 (총 {전체_문자수:,}자):")
        for 문자_타입, 개수 in 문자_특성.items():
            비율 = (개수 / 전체_문자수) * 100
            print(f"  • {문자_타입}: {개수:,}자 ({비율:.1f}%)")
        
        # 종성 분석
        print(f"\n단어 끝 글자 TOP 10:")
        for 순위, (글자, 빈도) in enumerate(분석_결과["종성_분석"].items(), 1):
            print(f"  {순위:2d}. '{글자}' ({빈도}회)")
        
        # 문체 분석
        문체_분석 = 분석_결과["문체_분석"]
        전체_문장수 = sum(문체_분석.values())
        print(f"\n문체 분석 (총 {전체_문장수}문장):")
        for 문체, 개수 in 문체_분석.items():
            비율 = (개수 / 전체_문장수) * 100
            print(f"  • {문체}: {개수}문장 ({비율:.1f}%)")
        
        # 처리 시간
        print(f"\n처리 시간: {분석_결과['처리_시간']:.3f}초")
        print("=" * 60)
```

   - 1부터 100까지 중 3의 배수만 출력하는 여러 가지 방법

2. **리스트 컴프리헨션 연습**
   - 주어진 리스트에서 조건에 맞는 요소들을 다양한 방법으로 필터링

3. **중첩 루프 기초**
   - 별표(*)로 다양한 패턴 출력하기

4. **enumerate와 zip 활용**
   - 두 리스트를 조합하여 새로운 데이터 구조 만들기

5. **break/continue 활용**
   - 사용자 입력을 받아 특정 조건에서 루프 제어

### 중급 문제 (5개)

6. **딕셔너리 컴프리헨션**
   - 복잡한 데이터 변환 및 필터링

7. **제너레이터 활용**
   - 메모리 효율적인 큰 수열 처리

8. **중첩 루프 최적화**
   - 이중 루프를 단일 루프로 변환하는 기법

9. **문자열 패턴 처리**
   - 한국어 텍스트에서 특정 패턴 찾기

10. **데이터 그룹화**
    - 복잡한 조건으로 데이터 분류 및 집계

### 고급 문제 (5개)

11. **고성능 알고리즘**
    - 중첩 루프를 사용한 정렬 알고리즘 구현

12. **스트림 처리**
    - 대용량 데이터를 청크 단위로 처리

13. **상태 기반 반복**
    - 복잡한 상태를 가진 루프 시스템

14. **패턴 매칭**
    - 정규표현식과 루프를 조합한 텍스트 처리

15. **종합 프로젝트**
    - 위의 한국어 텍스트 분석 시스템 확장
