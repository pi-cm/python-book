## 들어가며: 이름을 붙인다는 것

코드를 쓰는 우리는 컴퓨터라는 가상 세계(실제로는 메모리와 전기 신호로 이루어진 세계) 안의 창조주와 같습니다. 그 안에 무언가 "있으라!" 하고 만들 수 있고, 원하는 대로 바꾸거나 바뀌지 않게 할 수도 있죠. 그럼 무언가를 어떻게 만들까요? 간단합니다. 그것을 부를 **이름**과, 그것이 **무엇인지**를 말해 주면 돼요.

```python
X = "hello world"
```

`X`는 우리가 부르기 위한 이름이고, 그 이름은 `h-e-l-l-o- -w-o-r-l-d`라는 11글자(공백도 한 글자입니다)의 덩어리를 가리킵니다. 그런데 여기 쓰인 `=`는 수학 시간의 "같다"와 다릅니다. 굳이 그리자면 `X ← "hello world"`, 즉 "오른쪽 값에 왼쪽 이름을 붙여라"라는 화살표예요. 화살표는 키보드로 입력하기 힘드니 `=`를 빌려 쓰는 전통이 생긴 거죠. 정말로 "같은지" 물을 때는 3장에서 본 것처럼 `==`를 씁니다.

이름을 붙여 두면 값 대신 이름을 쓸 수 있습니다. `print(X)`는 `hello world`를 출력하고, `Y = X`라고 하면 같은 값에 `Y`라는 이름이 하나 더 붙어요. 이렇게 값에 붙인 이름을 **변수**라고 합니다. 이 장에서는 이름을 잘 짓는 법과, 이름이 가리키는 값의 종류(**자료형**)를 하나씩 살펴봅니다.

## 2.1 변수와 할당의 깊은 이해

### 파이썬 변수의 본질

파이썬에서 변수는 다른 언어와 달리 **객체에 대한 참조(reference)**입니다.

변수를 값을 담는 상자로 상상하기 쉽지만, 파이썬의 변수는 상자보다 **이름표**에 가깝습니다. 값(객체)은 메모리 어딘가에 따로 있고, 변수는 그 값에 붙은 이름표일 뿐이에요. 그 값이 메모리의 어디에 있는지는 `id()` 함수로 볼 수 있습니다.

```python
# 변수 할당의 내부 동작
이름 = "김철수"  # 문자열 객체 생성 후 '이름'이 참조
나이 = 25       # 정수 객체 생성 후 '나이'가 참조

# id() 함수로 객체의 고유 주소 확인
print(f"'이름' 변수가 참조하는 객체의 주소: {id(이름)}")
print(f"'나이' 변수가 참조하는 객체의 주소: {id(나이)}")
```

출력되는 숫자는 실행할 때마다, 컴퓨터마다 다릅니다. 숫자 자체보다 "값마다 고유한 주소가 있다"는 점이 중요해요. 그럼 `x = 1` 다음에 `x = 2`라고 하면 1이 들어 있던 자리의 값이 2로 바뀌는 걸까요? `id(x)`를 두 번 찍어 보면 서로 다른 숫자가 나옵니다. 값 1이 2로 변한 게 아니라, 이름표 `x`를 떼어서 새 값 2에 옮겨 붙인 거예요. 이름을 재활용했을 뿐 전혀 다른 값입니다.

> **Q. 그럼 이름표가 떨어진 이전 값 1은 어떻게 되나요?**  
> 많은 프로그래밍 언어에서는 메모리를 쓸 만큼 직접 빌리고(할당) 다 쓰면 직접 돌려줘야 합니다. 파이썬은 이 일을 알아서 해 줘요. 어떤 이름표도 붙어 있지 않은 값은 **가비지 컬렉터(garbage collector)** 라는 청소부가 회수해서 다른 곳에 쓸 수 있게 합니다. 편한 대신 컴퓨터가 그만큼 일을 더 하는 셈이니 장단점이 있지만, 그 노력이 성능 문제를 일으키지 않는 한 대부분의 경우에는 편한 쪽이 이득입니다.

### 변수 명명 규칙 (완전판)

변수 이름은 아무렇게나 지으면 될까요? 이름의 목적은 **뜻을 정확하게 전달하는 것**입니다. `a`보다 `age_in_years`가 낫고, `x2`보다 `사용자명`이 낫죠. 그 전에 파이썬이 정해 둔 몇 가지 규칙부터 지켜야 합니다.

- 글자(영문 대소문자, 한글 같은 유니코드 문자), 숫자, 밑줄 `_`만 쓸 수 있습니다. `!`, `@`, `#`, `$`, `%` 같은 기호는 안 됩니다.
- 숫자로 시작할 수 없습니다. `2name`은 안 되고 `name2`는 됩니다.
- 대소문자를 구분합니다. `x`와 `X`는 서로 다른 이름이에요.
- 파이썬이 이미 문법에 쓰고 있는 **예약어**는 쓸 수 없습니다.

#### 올바른 변수명

아래는 모두 파이썬이 받아들이는 이름입니다. 한글이나 그리스 문자도 쓸 수 있어요. 다만 다른 사람과 함께 쓰는 코드라면 영어 이름이 무난합니다. 프로그램을 옮기는 과정에서 인코딩(문자를 저장하는 방식)이 달라 한글이 깨지는 일도 있고, 막혔을 때 영어로 검색해야 답을 훨씬 많이 찾을 수 있거든요. 이 책은 읽기 쉽도록 예제에 한글 이름을 많이 씁니다.

```python
# 기본 규칙
name = "홍길동"
age_in_years = 30
_private_var = "은밀한 값"
MAX_SIZE = 100

# 한글 변수명 (완전 지원)
사용자명 = "김영희"
나이 = 28
한국_도시들 = ["서울", "부산", "대구"]

# 유니코드 변수명
π = 3.14159
α = 0.05
β = 0.95

# 언더스코어 활용
__private = "매우 은밀"  # 이름 맹글링은 클래스 안에서만 일어남 (여기서는 평범한 변수)
__init__ = "특수 메서드"  # 파이썬이 특별히 쓰는 이름 모양 (여기서는 평범한 변수, 실제로는 피할 것)
```

밑줄로 시작하는 이름에는 관례적인 뜻이 있습니다. `_private_var`처럼 밑줄 하나로 시작하면 "안에서만 쓰는 것이니 밖에서는 건드리지 마세요"라는 표시이고, 모두 대문자인 `MAX_SIZE`는 "바꾸지 않을 값(상수)"이라는 표시예요. 파이썬이 막지는 않지만 사람끼리의 약속입니다. 앞뒤로 밑줄 두 개가 붙은 `__init__` 같은 이름은 파이썬이 특별한 용도로 쓰는 이름이니 직접 만들어 쓰지 않는 것이 좋아요(11장에서 다룹니다).

#### 잘못된 변수명

하이픈(`-`)은 빼기 연산자로, 띄어쓰기는 이름이 둘로 끊긴 것으로 읽히기 때문에 이름에 쓸 수 없습니다. 아래 예제는 줄 앞에 `#`를 붙여 막아 두었으니, `#`를 지우고 실행해서 직접 `SyntaxError`(문법 오류)를 만나 보세요.

```python
# 이런 변수명들은 사용할 수 없습니다 (예제로만 표시)
# 2name = "숫자로 시작"      # SyntaxError
# class = "예약어 사용"       # SyntaxError  
# my-name = "하이픈 사용"     # SyntaxError
# my name = "공백 사용"       # SyntaxError

# 올바른 대안들
name2 = "숫자로 끝남"        # 올바름
class_name = "예약어 피하기"   # 올바름
my_name = "언더스코어 사용"    # 올바름
my_name_with_space = "공백 대신 언더스코어"  # 올바름
```

#### 예약어와 내장 이름

예약어가 무엇인지는 파이썬에게 직접 물어보면 됩니다.

```python
import keyword
print(keyword.kwlist)      # 예약어 35개
print(keyword.softkwlist)  # ['_', 'case', 'match', 'type'] (Python 3.12 기준)
```

`if`, `for`, `def`, `True` 같은 35개는 어떤 경우에도 이름으로 쓸 수 없습니다. 아래 줄의 **소프트 키워드**는 특정 문법 안에서만 예약어 역할을 하고, 다른 곳에서는 이름으로 써도 에러가 나지 않아요. 그래도 헷갈리니 피하는 게 좋습니다. 파이썬 버전에 따라 이 목록은 다를 수 있습니다. `match`와 `case`는 3.10에서, `type`은 3.12에서 추가됐거든요. 예약어도 시간이 지나며 새로 생깁니다.

더 조심해야 할 것은 `print`, `sum`, `list`, `input` 같은 **내장 함수 이름**입니다. 이들은 예약어가 아니라서 이름으로 써도 에러가 나지 않아요. 바로 그게 함정입니다.

```python
total = sum([1, 2, 3, 4])   # 10, 내장 함수 sum으로 합계를 구함
sum = 10                    # 그런데 sum이라는 이름에 값을 넣어 버리면
sum([1, 2])                 # TypeError: 'int' object is not callable
```

`sum = 10`을 실행하는 순간 이름표 `sum`이 합계 함수에서 떨어져 숫자 10에 붙습니다. 그 뒤로는 "숫자 10을 함수처럼 부를 수 없다"는 에러가 나죠. 그러니 파이썬이 이미 쓰고 있는 이름은 웬만하면 피하세요.

#### 이름 짓기 스타일 (PEP 8)

규칙만 지키면 어떤 이름이든 실행은 됩니다. 하지만 PEP 8의 말처럼 "코드는 쓰이는 것보다 훨씬 자주 읽힙니다." PEP 8은 파이썬 공식 스타일 가이드로, 이름만 보고도 그것이 함수인지 클래스인지 상수인지 알 수 있도록 다음과 같이 권합니다.

| 대상 | 스타일 | 예 |
|------|--------|----|
| 변수, 함수 | 소문자 + 밑줄 | `user_name`, `get_total()` |
| 클래스 | 단어 첫 글자 대문자 | `MyClassName` |
| 상수 | 대문자 + 밑줄 | `MAX_OVERFLOW` |
| 모듈(파일) | 짧은 소문자, 필요하면 밑줄 | `my_module.py` |
| 패키지(폴더) | 짧은 소문자, 밑줄은 권장하지 않음 | `mypackage` |

소문자 `l`, 대문자 `O`, 대문자 `I`는 한 글자 이름으로 쓰지 않는 게 좋습니다. 글꼴에 따라 숫자 1, 0과 구분이 안 되거든요. 이것은 강제 규칙이 아니라 권고입니다. 이미 다른 스타일로 일관되게 짠 코드에 새로 덧붙일 때는 그 코드의 스타일을 따르는 것이 더 중요해요. 핵심은 가독성이고, 가독성을 만드는 것은 일관성입니다.

### 메모리 효율성과 객체 재사용

자주 쓰는 값을 매번 새로 만들면 낭비겠죠? 그래서 파이썬(CPython)은 -5부터 256까지의 작은 정수를 미리 만들어 두고 계속 재사용합니다. 아래 예제에서 `a`와 `b`가 같은 물건(`is`가 `True`)인 이유예요.

```python
# 작은 정수는 파이썬이 미리 생성해둠 (-5 ~ 256)
a = 100
b = 100
print(f"a is b: {a is b}")  # True - 같은 객체를 참조

# 큰 정수는 미리 만들어 두지 않음
x = 1000
y = 1000
print(f"x is y: {x is y}")  # 파일 실행은 True, 대화형(>>>)은 False - 실행 방식에 따라 다름

# 문자열 인터닝 (String Interning)
str1 = "hello"
str2 = "hello"
print(f"str1 is str2: {str1 is str2}")  # True

# 하지만 실행 중에 만들어진 문자열은 따로 만들어짐
str3 = "".join(["hel", "lo"])
str4 = "".join(["hel", "lo"])
print(f"str3 is str4: {str3 is str4}")  # False - 값은 같지만 다른 객체
```

`x is y`의 결과는 실행 방법에 따라 다릅니다. 1000은 미리 만들어 두는 범위 밖인데도, 파일로 저장해 실행하면 `True`가 나와요(Python 3.12에서 확인). 파일은 통째로 한 번에 번역되면서 같은 값의 상수를 하나로 합치기 때문입니다. 대화형 모드(`>>>`)에서 한 줄씩 입력하면 따로 만들어져서 `False`가 나오고요. 반면 `join`처럼 실행 중에 만들어진 문자열은 어느 쪽으로 실행해도 값만 같은 별개의 객체라서 `False`입니다. 즉 `is`의 결과는 값이 아니라 **파이썬이 객체를 어떻게 만들고 재사용했는지**에 달려 있습니다. 그래서 값이 같은지 비교할 때는 항상 `==`를 쓰고, `is`는 3장에서 본 것처럼 `x is None`을 확인할 때만 쓰세요.

## 2.2 파이썬의 모든 데이터 타입 (완전판)

숫자 사과 2개와 글자 "사과"는 둘 다 사과지만, 더하고 빼는 방법이 전혀 다르죠. 값마다 종류가 있고, 종류에 따라 할 수 있는 일이 정해져 있습니다. 이 값의 종류를 **자료형(data type)** 이라고 하고, `type()`으로 확인할 수 있어요.

자료형을 나누는 기준 하나를 미리 알아 두면 좋습니다. 만든 뒤에 내용을 바꿀 수 있는 **가변(mutable)** 객체와, 바꿀 수 없는 **불변(immutable)** 객체예요. 이 절에서 볼 숫자, 문자열, 그리고 6장에서 볼 튜플은 불변입니다. "넘·스·튜(Number, String, Tuple)"로 외워 두세요. 불변 객체는 바뀌는 것처럼 보여도 실제로는 앞에서 본 `x = 2`처럼 새 객체가 만들어집니다.

### 숫자 타입 (Numeric Types)

#### int (정수)

손가락이 하나뿐이라면 접었다(0), 폈다(1) 두 가지만 셀 수 있죠. 손가락이 열 개라서 사람은 10진법을 쓰고, 스위치 하나가 켜짐과 꺼짐뿐인 컴퓨터는 2진법을 씁니다. 파이썬은 같은 수를 여러 진법으로 적을 수 있게 해 줘요. 앞에 `0b`를 붙이면 2진수, `0o`는 8진수, `0x`는 16진수입니다. 거꾸로 `bin(42)`, `oct(42)`, `hex(42)`는 수를 각 진법의 문자열로 바꿔 줍니다.

```python
# 다양한 진법 표현
십진수 = 42
이진수 = 0b101010      # 0b 접두사
팔진수 = 0o52          # 0o 접두사  
십육진수 = 0x2A        # 0x 접두사

print(f"모두 같은 값: {십진수} == {이진수} == {팔진수} == {십육진수}")

# 언더스코어로 가독성 향상 (Python 3.6+)
큰_숫자 = 1_000_000
매우_큰_숫자 = 999_999_999_999

# 정수는 크기 제한이 없음
거대한_수 = 2 ** 1000
print(f"2의 1000제곱의 자릿수: {len(str(거대한_수))}자리")
```

네 가지로 적었지만 모두 같은 42입니다. 적는 방법만 다를 뿐 저장되는 값은 하나예요. 큰 수 사이의 밑줄 `_`은 우리가 천 단위에 쉼표를 찍듯 눈으로 읽기 편하게 넣는 것이고, 파이썬은 무시합니다. 그리고 파이썬의 정수에는 크기 제한이 없어서 `2 ** 1000`의 302자리도 정확하게 계산해요.

#### float (부동소수점)

소수점이 있는 수는 `float`입니다. 아주 크거나 작은 수는 `e`를 써서 과학적 표기법으로 적을 수 있어요. `2.998e8`은 2.998 × 10⁸입니다. 무한대(`inf`)와 "숫자가 아님"을 뜻하는 `nan`이라는 특별한 값도 있는데, `nan`은 자기 자신과도 같지 않다는 묘한 성질이 있습니다. 계산이 잘못돼 생긴 "알 수 없는 값"끼리 같다고 할 수는 없으니까요.

```python
# 기본 실수
파이 = 3.14159
온도 = -15.5

# 과학적 표기법
광속 = 2.998e8        # 2.998 × 10^8
아보가드로_수 = 6.022e23
전자_질량 = 9.109e-31

# 특수 값들
양의_무한대 = float('inf')
음의_무한대 = float('-inf')
비수 = float('nan')   # Not a Number

print(f"∞ + 1 = {양의_무한대 + 1}")
print(f"NaN == NaN: {비수 == 비수}")  # False!

# 부동소수점 정밀도 문제
print(f"0.1 + 0.2 = {0.1 + 0.2}")  # 0.30000000000000004
print(f"0.1 + 0.2 == 0.3: {0.1 + 0.2 == 0.3}")  # False

# 해결책: decimal 모듈
from decimal import Decimal
정확한_계산 = Decimal('0.1') + Decimal('0.2')
print(f"정확한 계산: {정확한_계산}")  # 0.3
```

`0.1 + 0.2`가 `0.3`이 아닌 이유는 3.1절에서 사과를 셋이 나눠 먹는 비유로 설명했습니다. 2진수로는 `0.1`이 끝없는 소수라서 어딘가에서 잘라 저장하기 때문이에요. 정확해야 하는 계산에는 `Decimal`을 쓰고, 이때 `Decimal('0.1')`처럼 **문자열로** 넘겨야 잘리기 전의 정확한 값이 들어간다는 점을 기억하세요.

#### complex (복소수)

수학의 허수 i를 파이썬에서는 공학에서처럼 `j`로 씁니다. `3 + 4j`처럼 적으면 복소수가 되고, `.real`과 `.imag`로 실수부와 허수부를 꺼낼 수 있어요. 일상 프로그램에서는 쓸 일이 드물지만 신호 처리나 전기 회로 계산에서는 자주 등장합니다.

```python
# 복소수 생성 방법
복소수1 = 3 + 4j
복소수2 = complex(3, 4)
복소수3 = complex('3+4j')

print(f"실부: {복소수1.real}")  # 3.0
print(f"허부: {복소수1.imag}")  # 4.0
print(f"절댓값: {abs(복소수1)}")  # 5.0

# 복소수 연산
z1 = 1 + 2j
z2 = 2 - 1j
print(f"덧셈: {z1 + z2}")     # (3+1j)
print(f"곱셈: {z1 * z2}")     # (4+3j)
print(f"켤레: {z1.conjugate()}")  # (1-2j)
```

### 문자열 타입 (String Type)

#### str - 문자열의 모든 것

문자열은 글자들을 순서대로 늘어놓은 것입니다. 작은따옴표(`'`)와 큰따옴표(`"`) 중 무엇으로 감싸도 되고, 여러 줄이면 따옴표 세 개(`"""`)를 씁니다. 문자열 안에 작은따옴표를 넣고 싶으면 바깥을 큰따옴표로 감싸면 되죠. 한 가지 조심할 점이 있어요. 한글 워드프로세서에서 복사해 온 따옴표는 모양만 비슷한 다른 기호(“ ”)일 때가 많아서 파이썬이 알아보지 못합니다. 코드는 코드 편집기에서 직접 치세요.

문자열 안의 백슬래시(`\`)는 특별한 뜻을 가집니다. `\n`은 줄 바꿈, `\t`는 탭이에요. 이것을 **이스케이프 시퀀스**라고 합니다. 그런데 윈도우 경로 `C:\new`를 그냥 적으면 `\n`이 줄 바꿈으로 바뀌어 버리죠. 앞에 `r`을 붙인 **원시 문자열(raw string)** 은 백슬래시를 해석하지 않고 적은 그대로 둡니다. 파일 경로나 정규 표현식을 적을 때 편리해요.

앞에 `f`를 붙인 **f-string**은 중괄호 `{}` 안에 변수나 계산식을 넣으면 그 값으로 바꿔 줍니다. 중괄호 안의 콜론(`:`) 뒤에는 모양을 지정해요. `.2f`는 소수점 아래 2자리, `>10`은 10칸 안에서 오른쪽 정렬(`<`는 왼쪽, `^`는 가운데), `,`는 천 단위 쉼표입니다.

```python
# 다양한 문자열 생성 방법
단일_따옴표 = '안녕하세요'
이중_따옴표 = "반갑습니다"
삼중_따옴표 = """여러 줄
문자열
입니다"""

# Raw 문자열 (이스케이프 시퀀스 무시)
경로 = r"C:\Users\Documents\새 폴더"
정규식 = r"\d{3}-\d{4}-\d{4}"

# f-string (Python 3.6+) - 가장 권장되는 방식
이름 = "김파이썬"
나이 = 30
소개 = f"안녕하세요! 제 이름은 {이름}이고, 나이는 {나이}살입니다."

# f-string 고급 활용
숫자 = 3.14159
print(f"원주율: {숫자:.2f}")      # 소수점 2자리
print(f"원주율: {숫자:>10.3f}")   # 오른쪽 정렬, 10자리, 소수점 3자리

가격 = 1234567
print(f"가격: {가격:,}원")        # 천단위 구분자
print(f"가격: {가격:_}원")        # 언더스코어 구분자
```

`{숫자:>10.3f}`의 결과 `     3.142`를 보면 앞에 공백이 채워져 전체가 10칸입니다. 표처럼 줄을 맞춰 출력할 때 유용해요.

#### 인덱싱과 슬라이싱: 글자 꺼내기

문자열은 글자를 순서대로 보관하니까, 몇 번째 글자인지만 알면 꺼낼 수 있습니다. 번호(**인덱스**)는 0부터 시작하고, 음수는 뒤에서부터 셉니다. `[시작:끝]`처럼 범위를 주면 한 조각을 잘라 오는데(**슬라이싱**), 시작 위치는 포함하고 끝 위치는 포함하지 않아요.

```python
s = "Life is too short, You need Python"
print(s[0], s[-1])    # L n
print(s[0:4])         # Life  (0, 1, 2, 3번 글자)
print(s[19:])         # You need Python  (끝을 생략하면 마지막까지)
print(s[:17])         # Life is too short  (시작을 생략하면 처음부터)
print(s[19:-7])       # You need
print(s[999:])        # 빈 문자열: 슬라이싱은 범위를 넘어도 에러가 나지 않음
# print(s[999])       # IndexError: 인덱스 하나는 범위를 넘으면 에러

print("Py" + "thon", "하" * 3)   # Python 하하하
s[0] = "l"            # TypeError: 'str' object does not support item assignment
```

`+`는 문자열을 이어 붙이고, `*`는 반복합니다. 빼기는 없어요. "사과"에서 "과"를 빼면 무엇이 남아야 하는지 말이 되는 규칙을 정하기 어렵기 때문이죠. 마지막 줄처럼 첫 글자 하나만 바꾸려 해도 에러가 납니다. 문자열은 불변 객체니까요. 바꾸고 싶으면 `"l" + s[1:]`처럼 **새 문자열을 만들어야** 합니다. 리스트에서도 같은 인덱싱과 슬라이싱을 쓰는데, 6장에서 다시 만납니다.

#### 한글 문자열 처리 완전 가이드

컴퓨터는 숫자밖에 모르는데 글자는 어떻게 저장할까요? 글자마다 번호를 매겨 둔 표를 미리 만들어 두고, 번호를 저장했다가 화면에 보여 줄 때 표에서 글자를 찾아 그립니다. 가장 먼저 널리 쓰인 표가 **ASCII**로, 영문자·숫자·기호 등 128개만 들어 있어요. `ord("A")`를 실행하면 65, `chr(65)`는 `A`입니다.

128개로는 한글은커녕 다른 나라 글자도 담을 수 없죠. 그래서 세상의 모든 글자에 번호를 매기자는 **유니코드(Unicode)** 가 나왔습니다. 한글은 "가"(44032번)부터 "힣"(55203번)까지 11,172자가 각각 별도의 번호를 갖고 있어요. "각"은 "가"에 "ㄱ"을 더한 것이 아니라 44033번이라는 다른 글자입니다. 아래 예제의 `44032 <= ord(c) <= 55203`이 "완성형 한글인가?"를 묻는 조건인 이유죠. 자모 분리 함수도 이 번호가 초성·중성·종성 순서로 규칙적으로 배열된 것을 이용합니다.

번호를 파일에 저장할 때는 또 다른 약속, **인코딩**이 필요합니다. 가장 많이 쓰는 **UTF-8**은 자주 쓰는 영문·숫자는 1바이트로 짧게, 한글은 3바이트로, 드문 글자는 최대 4바이트로 저장합니다. 그래서 영문만 있는 UTF-8 파일은 ASCII 파일과 똑같아요. `len()`은 바이트가 아니라 **글자 수**를 세기 때문에 `"파이썬Programming"`의 길이는 3 + 11 = 14입니다.

```python
# 한글 인코딩 이해
한글_문자열 = "안녕하세요, 파이썬!"

# UTF-8 인코딩/디코딩
바이트_데이터 = 한글_문자열.encode('utf-8')
print(f"UTF-8 바이트: {바이트_데이터}")
복원된_문자열 = 바이트_데이터.decode('utf-8')
print(f"복원: {복원된_문자열}")

# 한글 길이 측정
문장 = "파이썬Programming"
print(f"전체 길이: {len(문장)}")         # 14
print(f"한글만: {''.join(c for c in 문장 if ord(c) >= 44032 and ord(c) <= 55203)}")

# 한글 자모 분리 (고급)
def 한글_자모_분리(글자):
    """한글 글자를 초성, 중성, 종성으로 분리"""
    if not (44032 <= ord(글자) <= 55203):
        return 글자, "", ""
    
    code = ord(글자) - 44032
    초성_index = code // (21 * 28)
    중성_index = (code % (21 * 28)) // 28
    종성_index = code % 28
    
    초성 = "ㄱㄲㄴㄷㄸㄹㅁㅂㅃㅅㅆㅇㅈㅉㅊㅋㅌㅍㅎ"[초성_index]
    중성 = "ㅏㅐㅑㅒㅓㅔㅕㅖㅗㅘㅙㅚㅛㅜㅝㅞㅟㅠㅡㅢㅣ"[중성_index]
    종성 = "" if 종성_index == 0 else "ㄱㄲㄳㄴㄵㄶㄷㄹㄺㄻㄼㄽㄾㄿㅀㅁㅂㅄㅅㅆㅇㅈㅊㅋㅌㅍㅎ"[종성_index - 1]
    
    return 초성, 중성, 종성

# 한글 자모 분리 예제
for 글자 in "한글":
    초성, 중성, 종성 = 한글_자모_분리(글자)
    print(f"{글자} = {초성} + {중성} + {종성}")
```

`encode('utf-8')`의 결과는 `b'\xec\x95\x88...'`처럼 알아보기 힘든 바이트 덩어리입니다. "안"이 `\xec\x95\x88` 세 바이트로 저장된 것이 보이죠. `decode('utf-8')`로 같은 약속을 써서 풀면 원래 문자열로 돌아옵니다. 저장할 때와 읽을 때 다른 인코딩을 쓰면 글자가 깨지는데, 한글 파일이 "깨져 보이는" 대부분의 원인이 이것이에요.

#### 문자열 메서드 완전 정리

**메서드**는 특정 자료형에 딸린 함수로, `값.메서드()`처럼 점을 찍어 부릅니다. 문자열에 어떤 메서드가 있는지는 `dir("")`로 전부 볼 수 있어요. 자주 쓰는 것은 공백 제거(`strip`), 대소문자 변환(`upper`, `lower`), 찾기(`find`, `count`), 바꾸기(`replace`), 나누기와 합치기(`split`, `join`) 정도입니다.

```python
텍스트 = "  Python Programming 파이썬 프로그래밍  "

# 공백 제거
print(f"strip(): '{텍스트.strip()}'")
print(f"lstrip(): '{텍스트.lstrip()}'")
print(f"rstrip(): '{텍스트.rstrip()}'")

# 대소문자 변환
영문 = "Hello Python World"
print(f"upper(): {영문.upper()}")
print(f"lower(): {영문.lower()}")
print(f"title(): {영문.title()}")
print(f"capitalize(): {영문.capitalize()}")
print(f"swapcase(): {영문.swapcase()}")

# 문자열 검색과 치환
문장 = "파이썬은 쉽고 강력한 프로그래밍 언어입니다. 파이썬을 배워보세요!"
print(f"'파이썬' 위치: {문장.find('파이썬')}")
print(f"'파이썬' 개수: {문장.count('파이썬')}")
print(f"'Java'로 치환: {문장.replace('파이썬', 'Java')}")

# 문자열 분할과 결합
단어들 = "사과,바나나,오렌지,포도".split(',')
print(f"분할: {단어들}")
print(f"결합: {' | '.join(단어들)}")

# 문자열 포매팅 (여러 방법)
이름, 점수 = "김학생", 95

# % 포매팅 (구식)
old_style = "%s님의 점수는 %d점입니다." % (이름, 점수)

# .format() 메서드
new_style = "{}님의 점수는 {}점입니다.".format(이름, 점수)
named_style = "{name}님의 점수는 {score}점입니다.".format(name=이름, score=점수)

# f-string (최신, 권장)
f_string = f"{이름}님의 점수는 {점수}점입니다."

print(f"구식: {old_style}")
print(f"신식: {new_style}")
print(f"명명: {named_style}")
print(f"f-string: {f_string}")
```

`replace`를 쓸 때 초보자가 자주 하는 실수가 있습니다. `문장.replace('파이썬', 'Java')`를 실행한 뒤 `문장`을 다시 찍어 보면 그대로예요. 문자열은 불변이라 메서드는 원본을 고치지 않고 **바뀐 새 문자열을 돌려줄 뿐**이거든요. 결과를 쓰려면 `문장 = 문장.replace(...)`처럼 다시 이름을 붙여야 합니다. 그리고 "Java은", "Java을"처럼 조사가 어색해진 것도 보이죠? 글자를 기계적으로 바꾸는 것과 말이 되게 바꾸는 것은 다릅니다.

`find`는 찾는 글자가 처음 나오는 인덱스를 돌려주고, 없으면 `-1`을 돌려줍니다. `split(',')`은 쉼표를 기준으로 잘라 리스트를 만들고, `' | '.join(...)`은 반대로 리스트를 `' | '`로 이어 붙여요. 문자열 포매팅은 세 가지 방식이 차례로 등장했습니다. `%` 방식이 가장 오래됐고, 그다음이 `.format()`, 가장 최근(Python 3.6)에 나온 것이 f-string이에요. 남의 코드를 읽으려면 셋 다 알아 두되, 새로 쓸 때는 f-string을 쓰면 됩니다.

### 바이트 관련 타입

#### bytes와 bytearray

문자열이 "글자의 나열"이라면 `bytes`는 "0~255 숫자(바이트)의 나열"입니다. 파일, 네트워크, 이미지처럼 컴퓨터가 실제로 주고받는 데이터는 결국 바이트예요. `b"Hello"`처럼 앞에 `b`를 붙여 만들고, 문자열의 `encode()`로도 만듭니다. `bytes`는 문자열처럼 불변이고, 내용을 고칠 수 있는 짝꿍이 `bytearray`입니다.

```python
# bytes (불변)
한글_바이트 = "안녕".encode('utf-8')
print(f"bytes: {한글_바이트}")
print(f"길이: {len(한글_바이트)}")  # UTF-8에서 한글은 글자당 3바이트

# bytearray (가변)
가변_바이트 = bytearray("Hello", 'utf-8')
가변_바이트[0] = ord('h')  # 첫 글자를 'h'로 변경
print(f"변경된 bytearray: {가변_바이트.decode('utf-8')}")

# 바이트 연산
바이트1 = b"Hello"
바이트2 = b" World"
결합 = 바이트1 + 바이트2
print(f"바이트 결합: {결합}")

# 16진수 변환
데이터 = "파이썬".encode('utf-8')
hex_string = 데이터.hex()
print(f"16진수: {hex_string}")
복원 = bytes.fromhex(hex_string)
print(f"복원: {복원.decode('utf-8')}")
```

"안녕" 두 글자의 `bytes` 길이가 6인 것을 확인해 보세요. UTF-8에서 한글이 글자당 3바이트이기 때문입니다. 16진수 문자열 `ed8c8cec9db4ec8dac`도 "파이썬" 세 글자가 3바이트씩, 모두 9바이트(16진수 18자리)로 저장된 모습이에요.

### 불린 타입 (Boolean Type)

"김밥하고 라면 주세요"와 "김밥 또는 라면 주세요"는 다른 주문이죠? 참과 거짓, 그리고 그것을 잇는 `and`, `or`, `not`이 불린의 세계입니다. 불린 값은 `True`와 `False` 둘뿐이에요(첫 글자는 대문자).

재미있게도 `bool`은 `int`의 자식 자료형입니다. `True`는 1, `False`는 0처럼 동작해서 `True + True`는 `2`예요. 그리고 `if`나 `while`의 조건 자리에는 불린이 아닌 값도 올 수 있는데, 이때 파이썬은 값을 참이나 거짓으로 판정합니다. 규칙은 간단해요. **0과 비어 있는 것은 거짓, 나머지는 모두 참**입니다. `[0]`은 0이 하나 "들어 있는" 리스트라서 참이에요.

```python
# 불린 기본값
참 = True
거짓 = False

# 불린으로 평가되는 값들
print("=== 거짓으로 평가되는 값들 ===")
거짓_값들 = [False, 0, 0.0, 0j, '', [], {}, set(), None]
for 값 in 거짓_값들:
    print(f"{repr(값):>8} -> {bool(값)}")

print("\n=== 참으로 평가되는 값들 ===")
참_값들 = [True, 1, -1, 3.14, 1+2j, 'a', [1], {'a': 1}, {1}]
for 값 in 참_값들:
    print(f"{repr(값):>8} -> {bool(값)}")

# 불린 연산
print(f"True and False: {True and False}")
print(f"True or False: {True or False}")
print(f"not True: {not True}")

# 단축 평가 (Short-circuit evaluation)
def 참_함수():
    print("참 함수 실행됨")
    return True

def 거짓_함수():
    print("거짓 함수 실행됨")
    return False

print("=== and 연산 단축 평가 ===")
result1 = 거짓_함수() and 참_함수()  # 첫 번째만 실행됨

print("=== or 연산 단축 평가 ===")
result2 = 참_함수() or 거짓_함수()   # 첫 번째만 실행됨
```

`None`도 거짓으로 판정되는 것을 보세요. `None`은 "값이 없음"을 뜻하는 특별한 값으로, 0과는 다릅니다. 0은 "개수가 0개"라는 값이 있는 것이고, `None`은 아예 값이 없는 거예요. 예를 들어 `print()`는 화면에 출력만 하고 돌려주는 값이 없어서, `y = print("hi")`라고 하면 `y`에는 `None`이 들어갑니다.

마지막 단축 평가 예제에서 각각 한 줄만 출력되는 이유는 3.2절에서 설명했습니다. `and`는 앞이 거짓이면, `or`는 앞이 참이면 뒤를 보지 않아요.

## 2.3 타입 힌트 (Type Hints) 완전 가이드

1장에서 파이썬은 **동적 타이핑** 언어라고 했죠. 변수에 어떤 종류의 값을 넣을지 미리 선언하지 않아도 됩니다. 편하지만, 코드가 길어지면 "이 함수에 숫자를 넣어야 하나, 문자열을 넣어야 하나?"가 헷갈리기 시작해요. **타입 힌트**는 이름 뒤에 `: 자료형`을, 함수의 괄호 뒤에 `-> 자료형`을 적어 "이런 값을 기대합니다"라고 메모해 두는 문법입니다.

중요한 점은 이름 그대로 **힌트**라는 거예요. 파이썬은 실행할 때 힌트를 검사하지 않습니다. `def f(x: int) -> int: return x * 2`에 `f("ab")`를 넣어도 에러 없이 `"abab"`가 나와요. 힌트는 사람과, mypy·Pylance 같은 검사 도구가 읽고 실수를 미리 알려 주는 데 씁니다.

### 기본 타입 힌트

`str`, `int`, `float`, `bool`은 그대로 쓰면 됩니다. 리스트나 딕셔너리처럼 여러 값을 담는 자료형은 대괄호 안에 "무엇을 담는지"까지 적어요. `List[int]`는 "정수를 담은 리스트"입니다. 아래 예제는 `typing` 모듈의 `List`, `Dict`를 쓰지만, Python 3.9부터는 `list[int]`, `dict[str, int]`처럼 소문자 내장 자료형을 바로 써도 됩니다. 새로 쓰는 코드라면 이쪽이 더 간단해요.

```python
from typing import List, Dict, Tuple, Set, Optional, Union, Any

# 기본 타입들
def 기본_타입_예제(
    이름: str,
    나이: int,
    키: float,
    결혼여부: bool
) -> str:
    return f"{이름}({나이}세, {키}cm, {'기혼' if 결혼여부 else '미혼'})"

# 컬렉션 타입들
학생_성적: List[int] = [90, 85, 92, 88]
사용자_정보: Dict[str, Any] = {"이름": "김학생", "나이": 20}
좌표: Tuple[float, float] = (37.5665, 126.9780)
고유_번호들: Set[int] = {1, 2, 3, 4, 5}
```

### 고급 타입 힌트

`Optional[int]`는 "정수 또는 `None`", `Union[str, int, float]`는 "셋 중 하나"라는 뜻입니다. Python 3.10부터는 `int | None`, `str | int | float`처럼 `|`로 짧게 쓸 수도 있어요. `Literal["대기", "진행", "완료"]`는 이 세 값만 허용한다는 뜻이고, `Callable[[int, int], int]`는 "정수 두 개를 받아 정수를 돌려주는 함수"를 뜻합니다. `TypedDict`는 딕셔너리에 어떤 키가 있고 각 값이 무슨 자료형인지 적어 두는 방법이에요.

```python
from typing import Callable, TypeVar, Generic, Protocol, Literal, List, Optional, Union
from typing import TypedDict  # Python 3.8+

# Optional과 Union
def 선택적_매개변수(이름: str, 나이: Optional[int] = None) -> str:
    if 나이 is None:
        return f"이름: {이름}"
    return f"이름: {이름}, 나이: {나이}"

def 여러_타입_허용(값: Union[str, int, float]) -> str:
    return f"받은 값: {값} (타입: {type(값).__name__})"

# Literal 타입 (Python 3.8+)
def 상태_확인(상태: Literal["대기", "진행", "완료"]) -> bool:
    return 상태 == "완료"

# Callable 타입
def 함수_실행기(함수: Callable[[int, int], int], a: int, b: int) -> int:
    return 함수(a, b)

더하기: Callable[[int, int], int] = lambda x, y: x + y
결과 = 함수_실행기(더하기, 10, 20)

# TypedDict (구조화된 딕셔너리)
class 학생정보(TypedDict):
    이름: str
    나이: int
    성적: List[int]

학생: 학생정보 = {
    "이름": "홍길동",
    "나이": 18,
    "성적": [90, 85, 92]
}
```

### 제네릭 타입과 타입 변수

접시 쌓기를 생각해 보세요. 맨 위에 올리고(push), 맨 위에서 꺼내는(pop) 구조가 **스택**입니다. 숫자를 쌓든 문자열을 쌓든 동작은 같죠. 그렇다고 숫자 스택과 문자열 스택을 따로 만들기는 번거롭습니다. `TypeVar`로 만든 `T`는 "아직 정하지 않은 어떤 자료형"을 뜻하는 자리표시자예요. `스택[int]()`라고 쓰는 순간 `T`가 `int`로 정해지고, 검사 도구는 이 스택에 문자열을 넣으면 경고해 줍니다. 이렇게 자료형을 나중에 채워 넣는 방식을 **제네릭**이라고 해요.

```python
from typing import TypeVar, Generic, List

# 타입 변수 정의
T = TypeVar('T')
K = TypeVar('K')
V = TypeVar('V')

# 제네릭 클래스
class 스택(Generic[T]):
    def __init__(self) -> None:
        self._items: List[T] = []
    
    def push(self, item: T) -> None:
        self._items.append(item)
    
    def pop(self) -> T:
        if not self._items:
            raise IndexError("빈 스택입니다")
        return self._items.pop()
    
    def is_empty(self) -> bool:
        return len(self._items) == 0

# 제네릭 함수
def 첫_번째_요소(리스트: List[T]) -> T:
    if not 리스트:
        raise ValueError("빈 리스트입니다")
    return 리스트[0]

# 사용 예제
숫자_스택 = 스택[int]()
숫자_스택.push(1)
숫자_스택.push(2)

문자_스택 = 스택[str]()
문자_스택.push("안녕")
문자_스택.push("파이썬")

숫자들 = [1, 2, 3, 4, 5]
첫_숫자 = 첫_번째_요소(숫자들)  # 타입: int
```

### Protocol (구조적 타이핑)

"오리처럼 걷고 오리처럼 꽥꽥거리면 오리다"라는 말이 있습니다. 파이썬은 원래 이렇게 생각해요. 어떤 집안(클래스) 출신인지보다 **무엇을 할 수 있는지**가 중요하다는 거죠. `Protocol`은 이 생각을 타입 힌트로 적는 방법입니다. 아래 `크기측정가능`은 "`__len__`을 가진 것이면 무엇이든"이라는 뜻이라서, 문자열·리스트·집합은 이 Protocol을 상속하지 않았는데도 모두 통과합니다. 클래스와 상속은 11장과 13장에서 자세히 배워요.

```python
from typing import List, Protocol

# Protocol 정의
class 크기측정가능(Protocol):
    def __len__(self) -> int: ...

class 정렬가능(Protocol):
    def __lt__(self, other) -> bool: ...

# Protocol을 사용하는 함수
def 길이_출력(객체: 크기측정가능) -> None:
    print(f"길이: {len(객체)}")

def 정렬_함수(항목들: List[정렬가능]) -> List[정렬가능]:
    return sorted(항목들)

# 사용 - 명시적 상속 없이도 동작
길이_출력("문자열")      # str은 __len__ 구현
길이_출력([1, 2, 3])   # list도 __len__ 구현
길이_출력({1, 2})      # set도 __len__ 구현

숫자들 = [3, 1, 4, 1, 5]
정렬된_숫자 = 정렬_함수(숫자들)  # int는 __lt__ 구현
```

## 2.4 새로운 Match-Case 문 (Python 3.10+)

값의 종류에 따라 처리를 다르게 하고 싶을 때가 많습니다. `match`는 값을 받아 위에서부터 차례로 `case`의 모양과 맞춰 보고, 처음 맞는 곳 하나만 실행해요. `case int()`는 "정수라면", `case [첫번째, *나머지]`는 "원소가 하나 이상인 리스트라면 첫 원소와 나머지로 나눠서", `case {"이름": 이름, "나이": 나이}`는 "이 두 키를 가진 딕셔너리라면"이라는 뜻입니다. 아무것에도 맞지 않으면 마지막 `case _`가 받아 줘요. 자세한 문법은 4.2절에서 다룹니다.

```python
def 데이터_타입_분석(값):
    """Match-Case를 사용한 타입별 처리"""
    match 값:
        # 기본 타입 매칭 (bool은 int의 자식이므로 int보다 먼저 검사)
        case bool():
            return f"불린: {'참' if 값 else '거짓'}"
        case int() if 값 > 0:
            return f"양의 정수: {값}"
        case int() if 값 < 0:
            return f"음의 정수: {값}"
        case int():
            return "영"
        case float():
            return f"실수: {값:.2f}"
        case str() if len(값) == 0:
            return "빈 문자열"
        case str():
            return f"문자열: '{값}' (길이: {len(값)})"
        case list() | tuple() if len(값) == 0:
            return "빈 시퀀스"
        case [단일_요소]:
            return f"단일 요소 리스트: {단일_요소}"
        case [첫번째, *나머지]:
            return f"리스트 - 첫번째: {첫번째}, 나머지 {len(나머지)}개"
        case dict() if not 값:
            return "빈 딕셔너리"
        case {"이름": 이름, "나이": 나이}:
            return f"사람 정보: {이름} ({나이}세)"
        case {"타입": "원", "반지름": r}:
            import math
            return f"원의 넓이: {math.pi * r * r:.2f}"
        case None:
            return "None 값"
        case _:  # 와일드카드 (모든 경우)
            return f"알 수 없는 타입: {type(값).__name__}"

# Match-Case 테스트
테스트_값들 = [
    42, -7, 0, 3.14, "", "안녕하세요", True, False,
    [], [1], [1, 2, 3, 4, 5], {}, 
    {"이름": "김철수", "나이": 30},
    {"타입": "원", "반지름": 5},
    None, complex(1, 2)
]

for 값 in 테스트_값들:
    결과 = 데이터_타입_분석(값)
    print(f"{repr(값):>20} -> {결과}")
```

실행 결과에서 `True -> 불린: 참`, `False -> 불린: 거짓`을 찾아보세요. 여기에는 함정이 하나 숨어 있습니다. 앞에서 본 것처럼 `bool`은 `int`의 자식이라서 `True`는 `int()` 패턴에도 맞아요. 그래서 `case bool()`을 `case int()`들 **아래로** 옮기면 `True -> 양의 정수: True`, `False -> 영`이 나오고 `case bool()`은 한 번도 실행되지 않습니다. `case`는 위에서부터 차례로 검사해 처음 맞는 하나만 실행하니, 더 좁은 경우(`bool`)를 넓은 경우(`int`)보다 위에 두어야 해요. 직접 줄을 옮겨 실행해 보면 차이를 확인할 수 있습니다.

## 2.5 입력과 출력 완전 가이드

1장에서 `print()`로 출력하고 `input()`으로 입력을 받아 봤습니다. 이번에는 둘을 실제 프로그램에서 쓸 만큼 단단하게 다듬어 봅니다.

### 입력 (Input) 처리

`input()`은 항상 문자열을 돌려준다고 했죠. 그래서 숫자가 필요하면 `int()`나 `float()`로 바꿔야 하는데, 사용자가 "스물다섯"처럼 숫자가 아닌 글자를 넣으면 `ValueError`가 나며 프로그램이 멈춰 버립니다. 사용자는 언제나 예상 밖의 값을 넣는다고 생각하는 게 안전해요. 아래 함수들은 `while True`로 계속 묻다가, 변환에 실패하면(`except ValueError`) 안내 문구를 보여 주고 다시 묻고, 올바른 값이 들어오면 그때 `return`으로 빠져나옵니다. 반복문은 5장, 예외 처리는 12장에서 자세히 배워요.

```python
def 안전한_입력():
    """타입 안전한 입력 함수들"""
    
    def 정수_입력(메시지: str, 최소값: int = None, 최대값: int = None) -> int:
        while True:
            try:
                값 = int(input(메시지))
                if 최소값 is not None and 값 < 최소값:
                    print(f"값은 {최소값} 이상이어야 합니다.")
                    continue
                if 최대값 is not None and 값 > 최대값:
                    print(f"값은 {최대값} 이하여야 합니다.")
                    continue
                return 값
            except ValueError:
                print("올바른 정수를 입력해주세요.")
    
    def 실수_입력(메시지: str) -> float:
        while True:
            try:
                return float(input(메시지))
            except ValueError:
                print("올바른 실수를 입력해주세요.")
    
    def 선택_입력(메시지: str, 선택지: list) -> str:
```

### 출력 (Output) 완전 활용

`print()`는 생각보다 많은 재료를 받습니다. 출력할 값들 외에 다음 네 가지를 이름을 붙여 넘길 수 있어요.

- `sep`: 값이 여러 개일 때 사이에 넣을 문자열. 기본은 공백 하나입니다.
- `end`: 출력이 끝난 뒤 붙일 문자열. 기본은 줄 바꿈(`\n`)이라서 `print`를 할 때마다 다음 줄로 넘어가요. `end=""`로 바꾸면 줄을 바꾸지 않습니다.
- `file`: 어디에 출력할지. 기본은 화면(표준 출력, `sys.stdout`)이고, 열어 둔 파일을 주면 파일에 써집니다. 에러 메시지는 관례적으로 `sys.stderr`에 써요.
- `flush`: 화장실 물을 생각하면 쉽습니다. 출력은 효율을 위해 잠깐 모아 두었다가 한꺼번에 내보내는데, `flush=True`는 "모으지 말고 지금 바로 내려라"라는 뜻이에요. 점이 하나씩 찍히는 로딩 표시처럼 출력 순간이 중요할 때 씁니다.

## 실습 프로젝트: 개인정보 관리 시스템

### 프로젝트 요구사항

한국인 개인정보를 체계적으로 관리하는 시스템을 만들어보겠습니다.

이 장에서 배운 것이 한 프로그램 안에 모두 모입니다. 이름·거주지는 문자열, 나이는 정수, 생년월일은 날짜, 직업·연락처처럼 비어 있을 수 있는 값은 `Optional[str]`과 `None`, 성별은 `Literal["남", "여"]`로 타입 힌트를 달았어요. 메뉴는 `match`로 고르고, 표는 f-string의 정렬(`:^10`)로 맞춥니다. 클래스(`class`)는 11장에서 배우니, 지금은 "사람 한 명의 정보를 묶어 두는 틀"(`한국인정보`)과 "여러 사람을 관리하는 틀"(`정보관리시스템`)이 있다는 정도로 읽으면 충분합니다.

```python
from typing import Dict, List, Optional, Literal
from datetime import datetime, date
import json

class 한국인정보:
    """한국인 개인정보를 관리하는 클래스"""
    
    def __init__(
        self,
        이름: str,
        생년월일: str,  # "YYYY-MM-DD" 형식
        성별: Literal["남", "여"],
        거주지: str,
        직업: Optional[str] = None,
        연락처: Optional[str] = None,
        이메일: Optional[str] = None
    ):
        self.이름 = 이름
        self.생년월일 = datetime.strptime(생년월일, "%Y-%m-%d").date()
        self.성별 = 성별
        self.거주지 = 거주지
        self.직업 = 직업
        self.연락처 = 연락처
        self.이메일 = 이메일
        self.등록일 = datetime.now()
    
    @property
    def 나이(self) -> int:
        """현재 나이 계산"""
        오늘 = date.today()
        나이 = 오늘.year - self.생년월일.year
        
        # 생일이 안 지났으면 1살 빼기
        if (오늘.month, 오늘.day) < (self.생년월일.month, self.생년월일.day):
            나이 -= 1
        
        return 나이
    
    @property
    def 연령대(self) -> str:
        """연령대 반환 (10대, 20대, ...)"""
        return f"{(self.나이 // 10) * 10}대"
    
    def 자기소개(self) -> str:
        """자기소개 문장 생성"""
        직업_부분 = f", {self.직업}" if self.직업 else ""
        return f"안녕하세요! 저는 {self.거주지}에 거주하는 {self.나이}세 {self.이름}입니다{직업_부분}."
    
    def to_dict(self) -> Dict:
        """딕셔너리로 변환"""
        return {
            "이름": self.이름,
            "생년월일": self.생년월일.isoformat(),
            "성별": self.성별,
            "거주지": self.거주지,
            "직업": self.직업,
            "연락처": self.연락처,
            "이메일": self.이메일,
            "나이": self.나이,
            "연령대": self.연령대,
            "등록일": self.등록일.isoformat()
        }
    
    def __str__(self) -> str:
        return f"{self.이름}({self.성별}, {self.나이}세, {self.거주지})"
    
    def __repr__(self) -> str:
        return f"한국인정보(이름='{self.이름}', 나이={self.나이}, 거주지='{self.거주지}')"

class 정보관리시스템:
    """개인정보 관리 시스템"""
    
    def __init__(self):
        self.사람들: List[한국인정보] = []
    
    def 등록(self, 사람: 한국인정보) -> None:
        """새 사람 정보 등록"""
        # 중복 체크
        for 기존_사람 in self.사람들:
            if 기존_사람.이름 == 사람.이름 and 기존_사람.생년월일 == 사람.생년월일:
                raise ValueError(f"{사람.이름}님은 이미 등록되어 있습니다.")
        
        self.사람들.append(사람)
        print(f"[O] {사람.이름}님이 등록되었습니다.")
    
    def 검색_이름(self, 이름: str) -> List[한국인정보]:
        """이름으로 검색"""
        return [사람 for 사람 in self.사람들 if 이름 in 사람.이름]
    
    def 검색_거주지(self, 거주지: str) -> List[한국인정보]:
        """거주지로 검색"""
        return [사람 for 사람 in self.사람들 if 거주지 in 사람.거주지]
    
    def 연령대_통계(self) -> Dict[str, int]:
        """연령대별 통계"""
        통계 = {}
        for 사람 in self.사람들:
            연령대 = 사람.연령대
            통계[연령대] = 통계.get(연령대, 0) + 1
        return dict(sorted(통계.items()))
    
    def 성별_통계(self) -> Dict[str, int]:
        """성별 통계"""
        통계 = {"남": 0, "여": 0}
        for 사람 in self.사람들:
            통계[사람.성별] += 1
        return 통계
    
    def 지역별_통계(self) -> Dict[str, int]:
        """지역별 통계"""
        통계 = {}
        for 사람 in self.사람들:
            # 거주지에서 시/도 추출
            지역 = 사람.거주지.split()[0]
            통계[지역] = 통계.get(지역, 0) + 1
        return dict(sorted(통계.items(), key=lambda x: x[1], reverse=True))
    
    def 전체_목록(self) -> None:
        """전체 등록자 목록 출력"""
        if not self.사람들:
            print("등록된 사람이 없습니다.")
            return
        
        print(f"\n{'='*70}")
        print(f"{'이름':^10} {'성별':^6} {'나이':^6} {'거주지':^15} {'직업':^15}")
        print(f"{'='*70}")
        
        for 사람 in sorted(self.사람들, key=lambda x: x.나이):
            직업 = 사람.직업 or "미입력"
            print(f"{사람.이름:^10} {사람.성별:^6} {사람.나이:^6} {사람.거주지:^15} {직업:^15}")
        
        print(f"{'='*70}")
        print(f"총 {len(self.사람들)}명 등록됨")
    
    def 통계_출력(self) -> None:
        """전체 통계 출력"""
        print(f"\n=== 등록자 통계 ===")
        print(f"총 등록자 수: {len(self.사람들)}명")
        
        # 성별 통계
        성별통계 = self.성별_통계()
        print(f"\n성별 분포:")
        for 성별, 수 in 성별통계.items():
            비율 = (수 / len(self.사람들)) * 100 if self.사람들 else 0
            print(f"  {성별}: {수}명 ({비율:.1f}%)")
        
        # 연령대 통계
        연령통계 = self.연령대_통계()
        print(f"\n연령대 분포:")
        for 연령대, 수 in 연령통계.items():
            비율 = (수 / len(self.사람들)) * 100
            바 = "█" * (수 * 20 // max(연령통계.values())) if 수 > 0 else ""
            print(f"  {연령대}: {수}명 ({비율:.1f}%) {바}")
        
        # 지역 통계
        지역통계 = self.지역별_통계()
        print(f"\n지역 분포 (상위 5개):")
        for i, (지역, 수) in enumerate(list(지역통계.items())[:5], 1):
            비율 = (수 / len(self.사람들)) * 100
            print(f"  {i}. {지역}: {수}명 ({비율:.1f}%)")
    
    def 저장_JSON(self, 파일명: str) -> None:
        """JSON 파일로 저장"""
        데이터 = [사람.to_dict() for 사람 in self.사람들]
        with open(파일명, 'w', encoding='utf-8') as f:
            json.dump(데이터, f, ensure_ascii=False, indent=2)
        print(f"{파일명}에 저장되었습니다.")

        print("3. 거주지 검색")
        print("4. 통계 보기")
        print("5. 새 사람 등록")
        print("6. JSON 저장")
        print("0. 종료")
        
        선택 = input("\n선택하세요 (0-6): ").strip()
        
        match 선택:
            case "1":
                시스템.전체_목록()
            
            case "2":
                이름 = input("검색할 이름: ").strip()
                결과 = 시스템.검색_이름(이름)
                if 결과:
                    print(f"\n'{이름}' 검색 결과:")
                    for 사람 in 결과:
                        print(f"  - {사람}")
                        print(f"    {사람.자기소개()}")
                else:
                    print(f"'{이름}'에 해당하는 사람을 찾을 수 없습니다.")
            
            case "3":
                거주지 = input("검색할 거주지: ").strip()
                결과 = 시스템.검색_거주지(거주지)
                if 결과:
                    print(f"\n'{거주지}' 거주자:")
                    for 사람 in 결과:
                        print(f"  - {사람}")
                else:
                    print(f"'{거주지}'에 거주하는 사람을 찾을 수 없습니다.")
            
            case "4":
                시스템.통계_출력()
            
            case "5":
                try:
                    print("\n새 사람 등록:")
                    이름 = input("이름: ").strip()
                    생년월일 = input("생년월일 (YYYY-MM-DD): ").strip()
                    성별 = input("성별 (남/여): ").strip()
                    거주지 = input("거주지: ").strip()
                    직업 = input("직업 (선택사항): ").strip() or None
                    연락처 = input("연락처 (선택사항): ").strip() or None
                    이메일 = input("이메일 (선택사항): ").strip() or None
                    
                    새_사람 = 한국인정보(이름, 생년월일, 성별, 거주지, 직업, 연락처, 이메일)
                    시스템.등록(새_사람)
                    
                except ValueError as e:
                    print(f"[X] 오류: {e}")
                except Exception as e:
                    print(f"[X] 입력 오류: {e}")
            
            case "6":
                파일명 = input("저장할 파일명 (기본: 개인정보.json): ").strip()
                if not 파일명:
                    파일명 = "개인정보.json"
                시스템.저장_JSON(파일명)
            
            case "0":
                print("프로그램을 종료합니다.")
                break
            
            case _:
                print("[X] 잘못된 선택입니다.")
```
