# 파이썬 완전 백과사전 1권 — 예제 코드

책에 실린 파이썬 코드를 장별 폴더에 실행할 수 있는 파일로 모았습니다.
파일 맨 위 주석에 원고의 장·절과 줄 번호가 있어 책의 어느 부분인지 바로 찾을 수 있어요.

## 준비

[uv](https://docs.astral.sh/uv/)가 설치되어 있으면 이 폴더에서 한 번만 실행합니다.

```bash
uv sync          # 파이썬 3.12와 예제에 필요한 패키지를 .venv에 설치
```

## 실행

예제 파일이 있는 폴더로 들어가서 실행하세요. 파일을 읽고 쓰는 예제가 많아 폴더 위치가 중요합니다.

```bash
cd 05-loops
uv run python 5.1_for_문_완전정복.py
```

14장 `src/` 아래 패키지 예제는 모듈로 실행합니다(본문 14.8절 참고).

```bash
cd 14-modules-packages/src
uv run python -m seoul_food_platform.best_practices_demo
```

## 파일 이름 규칙

| 이름 | 뜻 |
|------|----|
| `5.1_for_문_완전정복.py` | 그 절의 코드 블록을 차례대로 이어 붙인 파일 |
| `13.1-13.4_이어서_실행.py` | 앞 절의 정의를 이어 쓰는 장이라 여러 절을 한 파일로 묶은 것 |
| `..._따로_N.py` | 일부러 오류를 내거나, 키보드 입력이 필요하거나, 새 버전 전용이라 따로 뗀 블록 |
| `hr_management_system.py` 등 | 본문에서 파일 이름을 붙여 소개한 코드 |

## 실패해도 정상인 예제

`expected_errors.txt`에 이유와 함께 적혀 있습니다.

- 일부러 오류를 보여 주는 예제(2장의 일부, 부록 D 전체): 오류 메시지를 읽는 연습용입니다.
- 키보드 입력이 필요한 예제: 터미널에서 직접 실행해 값을 입력해 보세요.
- Python 3.13·3.14 전용 예제(부록 C): 해당 버전에서 실행하면 됩니다.
  `uv run --python 3.14 python 파일.py`
- `setup.py`: 옛 방식을 읽어 보라고 실은 참고용입니다.

## 만든 방법

원고가 원본이고 이 폴더는 원고에서 자동으로 뽑았습니다(저장소의 `tools/extract_examples.py`).
모든 파일은 `tools/check_examples.py`로 파이썬 3.12에서 실행해 확인했습니다.
